# Домашнее задание по Python

**Тема:** Методы списков

**Цель:** Закрепить навыки работы со списками и научиться использовать методы `insert()`, `index()`, `remove()`, `pop()`, `reverse()`, `count()`, `clear()`, `copy()`, `sort()`.

## Часть 1. Простые задания

### Задание 1. Добавление элементов — `insert()`

Дан список:

```python
fruits = ["яблоко", "банан", "апельсин", "груша"]
```

- Добавьте `"манго"` в начало списка.
- Добавьте `"киви"` на третью позицию.
- Добавьте `"ананас"` перед последним элементом.
- Выведите полученный список.

### Задание 2. Поиск элемента — `index()`

Дан список:

```python
cities = ["Москва", "Казань", "Сочи", "Самара", "Уфа"]
```

- Найдите индекс города `"Сочи"`.
- Найдите индекс города `"Уфа"`.
- Попросите пользователя ввести название города.
- Если город есть в списке, выведите его индекс. Иначе выведите сообщение `"Город не найден"`.

### Задание 3. Удаление элементов — `remove()`

Дан список:

```python
products = ["хлеб", "молоко", "сыр", "масло", "яйца"]
```

- Удалите `"масло"`.
- Удалите `"хлеб"`.
- Попросите пользователя ввести название продукта для удаления.
- Если такой продукт есть, удалите его.
- Выведите оставшиеся продукты.

### Задание 4. Удаление по индексу — `pop()`

Дан список:

```python
numbers = [10, 20, 30, 40, 50, 60]
```

- Удалите последний элемент списка.
- Удалите элемент с индексом `2`.
- Удалите первый элемент и сохраните его в переменной.
- Выведите удалённый элемент и итоговый список.

### Задание 5. Разворот списка — `reverse()`

Дан список:

```python
names = ["Анна", "Иван", "Мария", "Олег", "Дмитрий"]
```

- Выведите исходный список.
- Разверните список в обратном порядке.
- Выведите результат.
- Разверните список ещё раз и проверьте, что порядок восстановился.

### Задание 6. Подсчёт элементов — `count()`

Дан список:

```python
grades = [5, 4, 3, 5, 4, 5, 2, 3, 4, 5]
```

- Подсчитайте количество пятёрок.
- Подсчитайте количество четвёрок.
- Подсчитайте количество двоек.
- Попросите пользователя ввести оценку и выведите, сколько раз она встречается в списке.

### Задание 7. Очистка списка — `clear()`

Дан список:

```python
cart = ["телефон", "наушники", "чехол", "зарядка"]
```

- Выведите содержимое корзины.
- Выведите количество товаров в корзине.
- Полностью очистите корзину.
- Выведите содержимое и количество товаров после очистки.

### Задание 8. Копирование списка — `copy()`

Дан список:

```python
original = [10, 20, 30, 40, 50]
```

- Создайте копию списка с помощью `copy()`.
- Добавьте в копию число `100`.
- Удалите из копии число `20`.
- Выведите исходный список и копию.
- Убедитесь, что исходный список не изменился.

### Задание 9. Сортировка — `sort()`

Дан список:

```python
prices = [450, 120, 890, 230, 560, 100, 750]
```

- Отсортируйте цены по возрастанию.
- Выведите результат.
- Отсортируйте цены по убыванию.
- Выведите самую дешёвую и самую дорогую цену.

## Часть 2. Комбинированные задания

### Задание 10. Управление списком студентов

Дан список:

```python
students = ["Алексей", "Мария", "Иван", "Ольга", "Дмитрий"]
```

- Добавьте `"Анна"` на вторую позицию.
- Найдите индекс студента `"Иван"`.
- Удалите студента `"Ольга"`.
- Удалите последнего студента с помощью `pop()`.
- Отсортируйте имена по алфавиту.
- Выведите итоговый список студентов.

### Задание 11. Анализ результатов соревнования

Дан список очков участников:

```python
scores = [15, 20, 10, 25, 20, 30, 15, 20, 25]
```

- Подсчитайте, сколько участников получили `20` очков.
- Найдите индекс первого участника, набравшего `30` очков.
- Удалите первое значение `10`.
- Добавьте `35` очков в начало списка.
- Создайте копию списка.
- Отсортируйте копию по убыванию.
- Выведите исходный и отсортированный списки.

### Задание 12. Список любимых фильмов

Создайте пустой список `movies`.

- Попросите пользователя ввести названия пяти любимых фильмов и добавьте их в список.
- Выведите весь список.
- Попросите ввести название фильма, который нужно удалить.
- Если фильм присутствует в списке, удалите его.
- Добавьте новый фильм в начало списка.
- Отсортируйте названия по алфавиту.
- Выведите итоговый список.

### Задание 13. Редактор списка покупок

Создайте список:

```python
shopping = ["молоко", "хлеб", "яйца"]
```

Напишите программу с меню:

```text
1. Показать список
2. Добавить товар на указанную позицию
3. Удалить товар по названию
4. Удалить последний товар
5. Найти позицию товара
6. Отсортировать список
7. Очистить список
0. Выход
```

**Требования:**

- Программа должна работать в цикле `while` до выбора пункта `0`.
- Используйте `if`, `elif`, `else` для обработки команд.
- Для каждой операции применяйте соответствующий метод списка.
- Если пользователь пытается удалить или найти отсутствующий товар, выводите понятное сообщение.
- После каждой операции выводите обновлённый список.

- Названия переменных должны быть понятными.
