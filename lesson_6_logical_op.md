## Часть 1. Основы логических операторов

В Python логические операторы позволяют объединять несколько проверок или изменять результат одной проверки. Логические выражения дают результат `True` (истина) или `False` (ложь).

### 1. Оператор `and` — И

`and` возвращает `True`, только если **оба условия истинны**.

| Первое условие | Второе условие | Результат |
|---|---|---|
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

**Главное правило:** если хотя бы одно условие ложно, результат `and` будет `False`.

```python
print(True and True)
print(True and False)
print(False and True)
print(False and False)
```

### 2. Оператор `or` — ИЛИ

`or` возвращает `True`, если **хотя бы одно условие истинно**.

| Первое условие | Второе условие | Результат |
|---|---|---|
| `True` | `True` | `True` |
| `True` | `False` | `True` |
| `False` | `True` | `True` |
| `False` | `False` | `False` |

**Главное правило:** `or` возвращает `False`, только когда оба условия ложны.

```python
print(True or True)
print(True or False)
print(False or True)
print(False or False)
```

### 3. Оператор `not` — НЕ

`not` меняет логическое значение на противоположное.

| Исходное значение | Результат `not` |
|---|---|
| `True` | `False` |
| `False` | `True` |

**Главное правило:** `not` инвертирует результат выражения.

```python
print(not True)
print(not False)

print(not (5 > 10))
print(not (8 > 3))
```

## Часть 3. Использование в `if`, `elif`, `else`

Теперь применим операторы на практике. Условие в `if` может включать сразу несколько проверок.

### 1. Использование `and`

Пользователь может войти в систему, только если ему не менее 18 лет и у него есть пароль. Должны выполняться **оба условия**.

```python
age = 20
has_password = True

if age >= 18 and has_password:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Измените `age` на `16`, а затем `has_password` на `False`. Посмотрите, как меняется результат.

### 2. Использование `or`

Студент получает зачёт, если набрал не менее 60 баллов на экзамене **или** успешно выполнил дополнительную работу. Достаточно выполнить хотя бы одно условие.

```python
exam_score = 45
extra_work = True

if exam_score >= 60 or extra_work:
    print("Зачёт получен")
else:
    print("Зачёт не получен")
```

### 3. Использование `not`

Если компьютер не подключён к интернету, программа выводит предупреждение.

```python
is_connected = False

if not is_connected:
    print("Нет подключения к интернету")
else:
    print("Подключение есть")
```
