# Практическая работа по Python

## Тема: Инкапсуляция, атрибуты и свойства

**Материал для изучения:** [METANIT — «Инкапсуляция, атрибуты и свойства»](https://metanit.com/python/tutorial/7.2.php)

**Цель:** научиться ограничивать прямое изменение данных объектов, использовать приватные атрибуты, геттеры, сеттеры и свойства `@property`.

**Перед началом работы:** изучите материал по ссылке. Каждое задание выполняйте в отдельной программе. Готовые решения не приводятся — необходимо самостоятельно написать и проверить код.

---

## Часть 1. Открытые и приватные атрибуты

### Задание 1. Почему нужны ограничения?

Создайте класс `Person` с открытыми атрибутами `name` и `age`, которые задаются через `__init__()`.

1. Создайте объект человека с именем `Иван` и возрастом `20`.
2. Выведите его имя и возраст.
3. Измените возраст напрямую на `-50`.
4. Снова выведите информацию.
5. В комментарии к программе объясните, почему такое изменение может стать проблемой.

### Задание 2. Приватные атрибуты

Создайте класс `Student`, который хранит имя и возраст в приватных атрибутах `__name` и `__age`.

1. Передавайте значения через конструктор.
2. Добавьте метод `show_info()` для вывода данных.
3. Создайте объект и вызовите `show_info()`.
4. Попробуйте обратиться к `student.__age` напрямую и посмотрите, что произойдёт.
5. Объясните в комментарии, почему внутри метода `show_info()` доступ к атрибуту есть, а снаружи возникает ошибка.

### Задание 3. Попытка изменить приватный атрибут

Создайте класс `Car` с приватными атрибутами `__brand` и `__speed`. Добавьте метод `show_info()`.

1. Создайте автомобиль со скоростью `60` км/ч.
2. Выполните присваивание `car.__speed = 200`.
3. Вызовите `show_info()` и посмотрите на исходную скорость.
4. Выведите значение `car.__speed` отдельно.
5. Своими словами объясните, почему получились разные значения.

**Подсказка:** в Python двойное подчёркивание изменяет внутреннее имя атрибута (*name mangling*). Это не абсолютная защита данных.

## Часть 2. Геттеры и сеттеры

### Задание 4. Получение данных через геттер

Создайте класс `Book` с приватными атрибутами `__title` и `__author`.

1. Определите конструктор с параметрами `title` и `author`.
2. Добавьте методы `get_title()` и `get_author()`, которые возвращают соответствующие значения.
3. Создайте две книги.
4. Выведите их названия и авторов **только через геттеры**.

### Задание 5. Проверка возраста через сеттер

Создайте класс `Person` с приватным атрибутом `__age`.

1. В конструкторе установите возраст `18`.
2. Добавьте `get_age()` для получения возраста.
3. Добавьте `set_age(age)`, позволяющий устанавливать возраст только в диапазоне от `1` до `109` включительно.
4. При неверном значении выводите сообщение `Недопустимый возраст`, не изменяя прежнее значение.
5. Проверьте значения `25`, `-3`, `0`, `110`.
6. После каждой попытки выводите возраст через геттер.

### Задание 6. Защита стоимости товара

Создайте класс `Product` с приватными атрибутами `__name` и `__price`.

Реализуйте:

- `get_name()` — возвращает название товара;
- `get_price()` — возвращает цену;
- `set_price(price)` — изменяет цену, только если она больше нуля.

Создайте один товар с ценой `1500` рублей. Попробуйте установить цены `2000`, `-100` и `0`. После каждой попытки выводите текущую цену.

### Задание 7. Банковский счёт с контролем изменений

Создайте класс `BankAccount` с приватными атрибутами `__owner` и `__balance`.

1. Реализуйте `get_owner()` и `get_balance()`.
2. Реализуйте `set_balance(balance)`, разрешающий устанавливать только неотрицательный баланс.
3. Создайте счёт с балансом `5000`.
4. Попробуйте установить баланс `3500`, затем `-500`.
5. Проверьте, что отрицательное значение не сохранилось.
6. Не обращайтесь к `__balance` напрямую вне класса.

## Часть 3. Свойства `@property`

### Задание 8. Свойство только для чтения

Создайте класс `Passport` с приватным атрибутом `__number`, который задаётся через конструктор.

1. Создайте свойство `number` с помощью `@property`.
2. Получите номер через выражение `passport.number` без круглых скобок.
3. Попробуйте присвоить другое значение: `passport.number = "12345"`.
4. Посмотрите на ошибку и объясните, почему свойство нельзя изменить.

### Задание 9. Свойство с геттером и сеттером

Создайте класс `Temperature` с приватным атрибутом `__celsius`.

1. Реализуйте свойство `celsius` с помощью `@property`.
2. Реализуйте сеттер с помощью `@celsius.setter`.
3. В сеттере разрешайте температуру не ниже `-273.15` °C.
4. При попытке установить недопустимую температуру выводите предупреждение и сохраняйте старое значение.
5. Проверьте присваивания `25`, `-300`, `0` через `obj.celsius = ...`.
6. После каждого присваивания выводите `obj.celsius`.

### Задание 10. Защищённый рейтинг фильма

Создайте класс `Movie` с приватными атрибутами `__title` и `__rating`.

1. Для названия создайте свойство `title` **только для чтения**.
2. Для рейтинга создайте свойство `rating` с геттером и сеттером.
3. Рейтинг должен находиться в диапазоне от `0` до `10` включительно.
4. При неверном значении оставляйте прежний рейтинг.
5. Создайте фильм и проверьте рейтинги `8.5`, `12`, `-1`.
6. Попробуйте изменить название фильма через свойство `title` и объясните результат.

## Часть 4. Итоговые задания

### Задание 11. Профиль игрового персонажа

Создайте класс `GameCharacter` с приватными атрибутами:

- `__nickname` — имя персонажа;
- `__health` — здоровье;
- `__level` — уровень.

Требования:

1. Свойство `nickname` должно быть доступно только для чтения.
2. Свойство `health` должно разрешать значения от `0` до `100`.
3. Свойство `level` должно разрешать целые значения от `1` до `50`.
4. Некорректные изменения не должны портить данные объекта.
5. Метод `show_info()` должен выводить состояние персонажа.

Создайте персонажа и проверьте изменение здоровья и уровня допустимыми и недопустимыми значениями.

### Задание 12. Мини-проект «Учёт товаров»

Разработайте класс `StoreProduct`, представляющий товар в магазине.

Приватные атрибуты:

- `__name` — название;
- `__price` — цена;
- `__quantity` — количество на складе.

Реализуйте свойства:

- `name` — только для чтения;
- `price` — чтение и изменение, цена должна быть строго больше нуля;
- `quantity` — чтение и изменение, количество должно быть целым неотрицательным числом.

Добавьте метод `show_info()` для вывода характеристик товара.

**Порядок выполнения:**

1. Создайте три товара с разными характеристиками.
2. Выведите информацию о них.
3. Измените цену первого товара на допустимую.
4. Попробуйте установить отрицательную цену второму товару.
5. Измените количество третьего товара.
6. Попробуйте установить дробное и отрицательное количество.
7. Выведите итоговые характеристики всех товаров.
8. Объясните, какие свойства можно изменять, а какие доступны только для чтения.

## Требования к сдаче

- Каждое задание выполнить самостоятельно в Python.
- Для атрибутов, указанных как приватные, использовать двойное подчёркивание.
- Там, где требуются геттеры и сеттеры, не заменять их прямым изменением приватных атрибутов.
- Там, где требуются свойства, использовать `@property` и при необходимости `@имя_свойства.setter`.
- Проверить как корректные, так и некорректные значения.
- Не использовать наследование и другие темы, не рассмотренные на указанной странице.
