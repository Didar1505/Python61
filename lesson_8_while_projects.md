# Практическая работа: Доработка готовых программ с помощью цикла `while`

**Тема:** Цикл `while`, операторы `break`, `continue`, конструкция `while ... else`.

**Цель:** научиться добавлять циклы в существующие программы на Python, изменять логику их выполнения и правильно определять условия завершения.

## Инструкция

В каждом задании предоставлена готовая программа на Python, которая уже выполняет определённое действие.

Необходимо:

1. Изучить исходный код и запустить программу.
2. Понять, как она работает.
3. Доработать программу в соответствии с требованиями.
4. Использовать цикл `while` для реализации новой логики.
5. Проверить работу программы с разными входными данными.

**Не требуется переписывать программу с нуля.** Используйте существующий код и расширяйте его функциональность.

## Задание 1. Калькулятор

**Сложность:** лёгкое.

### Постановка задачи

Разработана простая программа-калькулятор, которая запрашивает два числа и выполняет одну из четырёх арифметических операций.

В настоящее время программа выполняет только одно вычисление и завершает работу.

Необходимо доработать калькулятор, чтобы пользователь мог выполнять несколько вычислений подряд.

### Исходный код

```python
a = float(input("Первое число: "))
b = float(input("Второе число: "))
operation = input("Операция (+, -, *, /): ")

if operation == "+":
    print("Результат:", a + b)
elif operation == "-":
    print("Результат:", a - b)
elif operation == "*":
    print("Результат:", a * b)
elif operation == "/":
    if b != 0:
        print("Результат:", a / b)
    else:
        print("Деление на ноль запрещено")
else:
    print("Неизвестная операция")
```

### Что нужно добавить

1. После каждого вычисления программа должна спрашивать, хочет ли пользователь продолжить.
2. При вводе `да` калькулятор должен снова запрашивать два числа и операцию.
3. При вводе `нет` программа должна завершаться.
4. Если введена неизвестная операция, программа должна сообщить об ошибке и позволить повторить вычисление.

**Обязательное условие:** использовать `while`.

## Задание 2. Симулятор лифта

**Сложность:** лёгкое.

### Постановка задачи

Создана программа для управления лифтом в девятиэтажном здании.

Изначально лифт находится на первом этаже. Пользователь выбирает этаж назначения, а программа сообщает направление движения.

Необходимо добавить имитацию движения лифта между этажами.

### Исходный код

```python
current_floor = 1

target_floor = int(input("Выберите этаж (1–9): "))

if target_floor > current_floor:
    print("Лифт движется вверх")
elif target_floor < current_floor:
    print("Лифт движется вниз")
else:
    print("Лифт уже на этом этаже")

print("Текущий этаж:", current_floor)
```

### Что нужно добавить

1. Лифт должен перемещаться по одному этажу за итерацию цикла.
2. При движении вверх номер текущего этажа увеличивается на 1.
3. При движении вниз номер текущего этажа уменьшается на 1.
4. После каждого перемещения выводится текущий этаж.
5. Цикл завершается, когда лифт достигает выбранного этажа.
6. Если пользователь ввёл этаж вне диапазона 1–9, движение не начинается.

### Пример ожидаемой работы

```text
Выберите этаж (1–9): 5
Лифт движется вверх
Текущий этаж: 2
Текущий этаж: 3
Текущий этаж: 4
Текущий этаж: 5
Лифт прибыл!
```

**Обязательное условие:** использовать `while` с проверкой текущего и целевого этажей.

## Задание 3. Зарядка аккумулятора

**Сложность:** лёгкое.

### Постановка задачи

Создан симулятор зарядки аккумулятора смартфона.

Изначально аккумулятор заряжен на 35%. За одну минуту уровень заряда увеличивается на определённый процент.

Сейчас программа рассчитывает заряд только за одну минуту.

Необходимо реализовать полный процесс зарядки до 100%.

### Исходный код

```python
battery = 35

speed = int(input("Заряд за минуту (%): "))

battery += speed

if battery > 100:
    battery = 100

print("Заряд аккумулятора:", battery, "%")
```

### Что нужно добавить

1. Программа должна постепенно заряжать аккумулятор до 100%.
2. Каждая итерация цикла соответствует одной минуте.
3. После каждой минуты отображается текущий заряд.
4. Необходимо подсчитать количество минут зарядки.
5. Заряд не должен превышать 100%.
6. Если скорость зарядки меньше или равна нулю, программа должна вывести ошибку и не начинать процесс.

### Пример ожидаемой работы

```text
Заряд за минуту (%): 20
Минута 1: 55%
Минута 2: 75%
Минута 3: 95%
Минута 4: 100%

Аккумулятор полностью заряжен!
Время зарядки: 4 мин.
```

**Обязательное условие:** использовать `while`.

## Задание 4. Космическая ракета

**Сложность:** среднее.

### Постановка задачи

Разработана простая программа, моделирующая запуск космической ракеты.

Перед стартом программа выполняет один шаг обратного отсчёта. После этого выводит сообщение о запуске и рассчитывает расход топлива за одну секунду полёта.

Необходимо реализовать полноценный обратный отсчёт и полёт до окончания топлива.

### Исходный код

```python
countdown = 5
fuel = 40
consumption = 8

print("До запуска:", countdown)
countdown -= 1

print("Ракета запущена!")

fuel -= consumption
print("Остаток топлива:", fuel)
```

### Что нужно добавить

1. Реализовать обратный отсчёт от 5 до 1.
2. После завершения отсчёта вывести «Ракета запущена!».
3. После запуска ракета должна расходовать по 8 единиц топлива каждую секунду.
4. После каждой секунды выводить остаток топлива.
5. Полёт должен продолжаться, пока топливо не закончится.
6. Подсчитать продолжительность полёта в секундах.
7. После окончания топлива вывести сообщение «Топливо закончилось. Полёт завершён».

**Обязательное условие:** использовать два последовательных цикла `while` — для обратного отсчёта и полёта.

## Задание 5. Банкомат: проверка PIN-кода

**Сложность:** среднее.

### Постановка задачи

Разработана программа проверки PIN-кода банковской карты.

В настоящее время пользователь может ввести PIN-код только один раз.

Необходимо добавить ограниченное количество попыток ввода и автоматическую блокировку доступа.

### Исходный код

```python
correct_pin = "1234"

pin = input("Введите PIN-код: ")

if pin == correct_pin:
    print("Доступ разрешён")
else:
    print("Неверный PIN-код")
```

### Что нужно добавить

1. Пользователь должен иметь максимум 3 попытки ввода PIN-кода.

3. Если PIN-код введён правильно, цикл немедленно завершается.
4. Если все три попытки закончились, вывести «Карта заблокирована».
5. Сообщение о блокировке не должно появляться после успешного ввода PIN-кода.

**Обязательное условие:** использовать `while`, `break` и `else` цикла.

## Задание 6. Управление роботом

**Сложность:** среднее.

### Постановка задачи

Создана программа для управления роботом на координатной плоскости.

Робот начинает движение в точке `(0, 0)` и может перемещаться вверх, вниз, влево и вправо.

Сейчас программа выполняет только одну команду движения.

Необходимо реализовать непрерывное управление роботом.

### Исходный код

```python
x = 0
y = 0

command = input("Направление (w/a/s/d): ")

if command == "w" and y < 5:
    y += 1
elif command == "s" and y > 0:
    y -= 1
elif command == "a" and x > 0:
    x -= 1
elif command == "d" and x < 5:
    x += 1

print("Позиция робота:", x, y)
```

### Что нужно добавить

1. Программа должна многократно запрашивать направление движения.
2. Команды: `w` — вверх, `s` — вниз, `a` — влево, `d` — вправо.
3. После каждого перемещения выводить новые координаты.
4. Робот не может выходить за границы: `0 <= x <= 5` и `0 <= y <= 5`.
5. Если робот пытается выйти за границы, вывести сообщение «Движение невозможно».
6. Если введена неизвестная команда, вывести «Неизвестная команда» и продолжить работу.
7. Команда `exit` должна завершать программу.

**Обязательное условие:** использовать `while True`, `break` и `continue`.

## Задание 7. Проверка простого числа

**Сложность:** среднее.

### Постановка задачи

Создана программа для проверки делимости числа.

Сейчас программа проверяет, делится ли введённое число на 2.

Необходимо расширить программу, чтобы она определяла, является ли число простым.

Простое число — натуральное число больше 1, которое делится без остатка только на 1 и само себя.

### Исходный код

```python
number = int(input("Введите число: "))

divisor = 2

if number % divisor == 0:
    print("Число делится на", divisor)
else:
    print("Число не делится на", divisor)
```

### Что нужно добавить

1. Программа должна последовательно проверять делители начиная с 2.
2. Проверка должна продолжаться, пока делитель меньше введённого числа.
3. Если найден делитель без остатка, вывести «Число составное» и остановить проверку.
4. Если ни одного делителя не найдено, вывести «Число простое».
5. Числа меньше 2 не должны считаться простыми.

**Обязательное условие:** использовать `while`, `break` и `else` цикла.

### Пример ожидаемой работы

```text
Введите число: 17
Число простое
```

```text
Введите число: 21
Число составное
```

## Задание 8. Игра «Битва с монстром»

**Сложность:** среднее.

### Постановка задачи

Создана простая боевая система.

Игрок сражается с монстром. У каждого персонажа есть определённое количество здоровья.

Игрок наносит 7 единиц урона за атаку, монстр отвечает и наносит 4 единицы урона.

Сейчас программа выполняет только один раунд боя.

Необходимо организовать полноценное сражение до победы одной из сторон.

### Исходный код

```python
player_hp = 30
monster_hp = 25

player_damage = 7
monster_damage = 4

monster_hp -= player_damage
print("Игрок атаковал монстра!")

if monster_hp > 0:
    player_hp -= monster_damage
    print("Монстр атаковал игрока!")

print("Здоровье игрока:", player_hp)
print("Здоровье монстра:", monster_hp)
```

### Что нужно добавить

1. Бой должен продолжаться, пока оба персонажа живы.
2. В каждом раунде игрок первым атакует монстра.
3. Если монстр погиб, ответной атаки быть не должно.
4. Если монстр жив, он атакует игрока.
5. После каждого раунда выводить здоровье обоих персонажей.
6. Подсчитывать количество раундов.
7. После завершения боя вывести «Игрок победил!» или «Монстр победил!».

Дополнительное условие: здоровье персонажей не должно отображаться как отрицательное число.

**Обязательное условие:** использовать `while` с двумя условиями продолжения боя.

## Задание 9. Торговый автомат

**Сложность:** среднее.

### Постановка задачи

Создана программа торгового автомата по продаже напитков.

Цена напитка — 75 рублей. Пользователь вносит деньги, после чего программа проверяет, хватает ли суммы для покупки.

Сейчас автомат принимает деньги только один раз.

Необходимо реализовать постепенное внесение денег.

### Исходный код

```python
price = 75

money = int(input("Внесите деньги: "))

if money >= price:
    change = money - price
    print("Заберите напиток")
    print("Сдача:", change)
else:
    print("Недостаточно денег")
    print("Не хватает:", price - money)
```

### Что нужно добавить

1. Пользователь может вносить деньги несколько раз.
2. Все внесённые положительные суммы должны накапливаться.
3. После каждого внесения денег показывать, сколько ещё не хватает для покупки.
4. Когда накопленная сумма достигнет 75 рублей, выдать напиток.
5. Если пользователь внесёт больше 75 рублей, вывести размер сдачи.
6. Если пользователь введёт отрицательное число, вывести ошибку и не учитывать его.
7. Если пользователь введёт 0, отменить покупку и вернуть все внесённые деньги.

**Обязательное условие:** использовать `while`, `break` и `continue`.

### Пример ожидаемой работы

Внесите деньги: 30

## Задание 10. Система охлаждения процессора

**Сложность:** среднее.

### Постановка задачи

Разработана простая система контроля температуры процессора.

Начальная температура процессора — 92°C. Система охлаждения за один цикл работы снижает температуру на определённое количество градусов.

Сейчас программа выполняет только один цикл охлаждения.

Необходимо реализовать автоматическое охлаждение до безопасной температуры.

### Исходный код

```python
temperature = 92
safe_temperature = 45

cooling = int(input("Снижение температуры за цикл: "))

temperature -= cooling

print("Температура:", temperature, "°C")

if temperature <= safe_temperature:
    print("Температура безопасна")
else:
    print("Требуется охлаждение")
```

### Что нужно добавить

1. Охлаждение должно повторяться, пока температура выше 45°C.
2. На каждой итерации температура уменьшается на заданное количество градусов.
3. После каждой итерации выводить новую температуру процессора.
4. Необходимо подсчитать количество циклов охлаждения.
5. Температура в модели не должна опускаться ниже 45°C.
6. Когда достигнута безопасная температура, вывести «Охлаждение завершено».
7. Если введённая скорость охлаждения меньше или равна нулю, вывести ошибку и не запускать охлаждение.

### Пример ожидаемой работы

```text
Снижение температуры за цикл: 10

Цикл 1: 82°C
Цикл 2: 72°C
Цикл 3: 62°C
Цикл 4: 52°C
Цикл 5: 45°C

Охлаждение завершено!
Количество циклов: 5
```

**Обязательное условие:** использовать `while`.
