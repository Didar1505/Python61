## Первое занятие

### Задача 1. Билет со скидкой

Билет стоит 500 рублей.

- Посетителям младше 12 лет предоставляется скидка 50%.
- Посетителям от 12 до 17 лет включительно предоставляется скидка 20%.
- Остальным посетителям скидка не предоставляется.

Получите возраст посетителя и выведите стоимость билета.

**Примеры:**

- возраст `10` → стоимость `250.0`;
- возраст `12` → стоимость `400.0`;
- возраст `18` → стоимость `500`.

---

### Задача 2. Пять результатов викторины

Участник прошёл пять раундов викторины. В каждом раунде он получает от 0 до 10 баллов.

Получите пять результатов и выведите:

1. Общую сумму баллов.
2. Количество успешных раундов.

Раунд считается успешным, если участник набрал не меньше 6 баллов.

**Пример:**

```text
Баллы: 7, 4, 6, 10, 2
Всего баллов: 29
Успешных раундов: 3
```

### Задача 3. Расходы до команды «стоп»

Пользователь по одному вводит расходы за день.

- Число `0` означает, что расходов больше нет.
- Положительное число нужно добавить к общей сумме.
- Отрицательное число считается ошибочным: его не нужно добавлять, но ввод должен продолжаться.

Выведите общую сумму положительных расходов.

**Пример:**

```text
Ввод: 120, 80, -5, 50, 0
Общая сумма: 250
```

### Задача 4. Ремонт счётчика посещаемости

Программа должна получить четыре отметки посещаемости:

- `1` — студент присутствовал;
- `0` — студент отсутствовал.

После ввода программа должна вывести общее количество присутствий. В программе ниже есть две логические ошибки.

```python
for day in range(4):
    attended = 0
    mark = int(input("Отметка: "))
    if mark == 1:
        attended = attended + 1
    print("Посещений:", attended)
```

Выполните задания:

1. Не запуская программу, определите, что она выведет для отметок `1, 1, 0, 1`.
2. Найдите две логические ошибки.
3. Исправьте программу.
4. Проверьте исправленную программу для отметок `1, 1, 0, 1` и `0, 0, 0, 0`.

### Задача 8. Лаборатория ошибок

#### Программа А

for price in prices:
