# Домашнее задание по Python

**Тема:** Основы работы со списками

## Задание 1. Мои любимые числа

Создайте список из 6 любых целых чисел.

1. Выведите весь список.
2. Выведите первый и последний элементы.
3. Выведите количество элементов с помощью `len()`.
4. Найдите сумму всех чисел с помощью `sum()`.
5. Найдите максимальное и минимальное число с помощью `max()` и `min()`.

## Задание 2. Список покупок

Дан список:

```python
products = ["Хлеб", "Молоко", "Яйца", "Сыр"]
```

1. Выведите исходный список.
2. Добавьте `"Масло"` с помощью `append()`.
3. Добавьте `"Чай"` и `"Сахар"` с помощью `extend()`.
4. Удалите второй элемент списка с помощью `del`.
5. Выведите обновлённый список и количество товаров.

## Задание 3. Проверка наличия товара

Дан список:

```python
fruits = ["яблоко", "банан", "груша", "апельсин", "киви"]
```

1. Запросите у пользователя название фрукта.
2. Проверьте, есть ли фрукт в списке, используя `in`.
3. Если фрукт найден, выведите `"Фрукт есть в списке"`.
4. Если фрукт отсутствует, выведите `"Фрукт не найден"`.
5. Если фрукт отсутствует, добавьте его в список с помощью `append()`.
6. Выведите итоговый список.

## Задание 4. Работа со срезами

Дан список:

```python
numbers = [10, 20, 30, 40, 50, 60, 70, 80]
```

Выведите:

1. Первые три элемента.
2. Последние три элемента.
3. Элементы со второго по пятый включительно.
4. Каждый второй элемент.
5. Список в обратном порядке.

Используйте только индексацию и срезы.

## Задание 5. Создание списка с клавиатуры

1. Создайте пустой список `numbers = []`.
2. Запросите у пользователя 5 целых чисел.
3. Добавьте каждое число в список с помощью `append()`.
4. Выведите полученный список.
5. Выведите сумму и среднее арифметическое всех чисел.

## Задание 6. Объединение списков

Даны два списка:

```python
group1 = ["Анна", "Иван", "Олег"]
group2 = ["Мария", "Денис", "Алина"]
```

1. Объедините два списка с помощью оператора `+`.
2. Выведите общий список студентов.
3. Выведите количество студентов.
4. Создайте новый список, повторив `group1` два раза с помощью оператора `*`.
5. Выведите полученный список.

## Задание 7. Изменение оценок

Дан список:

```python
grades = [3, 4, 5, 2, 4, 3]
```

1. Выведите исходные оценки.
2. Замените первую оценку на `5`.
3. Замените последнюю оценку на `4`.
4. Удалите третью оценку с помощью `del`.
5. Добавьте новую оценку `5` в конец списка.
6. Выведите обновлённый список и средний балл.

## Задание 8. Список и строка

Дана строка:

```python
word = "Python"
```

1. Выведите первый и последний символы строки.
2. Преобразуйте строку в список символов с помощью `list()`.
3. Выведите полученный список.
4. Замените первый элемент списка на `"J"`.
5. Добавьте символ `"!"` в конец списка.
6. Выведите изменённый список.
7. Объясните в комментарии, почему можно изменить элемент списка, но нельзя напрямую изменить символ строки по индексу.
