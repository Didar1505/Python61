## Подготовка

1. Создайте папку `snake_game` и файл `main.py`.
2. Откройте папку в своей среде разработки (например, VS Code, IDLE или PyCharm).
3. Убедитесь, что установлен Python 3 с поддержкой Tkinter. Запустите `python -m turtle`: должно появиться демонстрационное окно. На Windows также можно использовать `py -m turtle`.

### Правила игры

- Змейка начинает игру с трёх сегментов и движется вправо.
- Стрелки или WASD меняют направление. Перемещение — ровно одна клетка за шаг.
- За съеденную еду добавляется один сегмент и одно очко.
- Столкновение со стеной или собственным телом завершает игру.
- Клавиша R после завершения запускает новый раунд, рекорд текущего запуска сохраняется.
- Если змейка заняла всё поле, отображается победа.

### Кто за что отвечает

| Класс | Ответственность | Основные методы |
|---|---|---|
| `Snake` | Тело, направление и движение | `move()`, `up()`, `extend()`, `reset()` |
| `Food` | Еда и поиск свободной клетки | `refresh()` |
| `Scoreboard` | Очки, рекорд, сообщения | `increase_score()`, `reset()`, `game_over()` |
| `Game` | Координация объектов и цикл игры | `step()`, `tick()`, `restart()`, `start()` |

Классы помогают не смешивать управление змейкой, размещение еды и отображение счёта. Например, изменение оформления еды не требует переписывать алгоритм движения. До этапа 10 роль координатора временно выполняет код в конце файла.

## Этап 1. Создание игрового окна

### Что реализуем

Окно 640 × 640 пикселей с тёмным фоном, рамкой игрового поля и свободным местом для счёта сверху.

### 1.1. Добавьте в начало пустого `main.py`


```python
import random
import turtle

CELL = 20
MIN_X, MAX_X = -280, 280
MIN_Y, MAX_Y = -280, 240
START_DELAY = 150
START_POSITIONS = [(0, 0), (-CELL, 0), (-2 * CELL, 0)]
```

`CELL` — размер одной клетки, 20 пикселей. Остальные константы задают допустимые координаты **центров** клеток. `START_POSITIONS` пригодится на следующем этапе. `START_DELAY` — задержка в миллисекундах между шагами игры. Заглавные имена обозначают настройки, которые не следует случайно менять во время игры.

### 1.2. Ниже добавьте функции создания окна и проверки границы


```python
def create_screen():
    screen = turtle.Screen()
    screen.setup(640, 640)
    screen.title('Змейка — Python Turtle')
    screen.bgcolor('#17212b')
    screen.tracer(0)

    # Рамка проходит по внешним краям игровых клеток.
    border = turtle.Turtle()
    border.hideturtle()
    border.speed(0)
    border.color('white')
    border.penup()
    border.goto(MIN_X - CELL / 2, MIN_Y - CELL / 2)
    border.pendown()
    for x, y in [(MAX_X + CELL / 2, MIN_Y - CELL / 2),
                 (MAX_X + CELL / 2, MAX_Y + CELL / 2),
                 (MIN_X - CELL / 2, MAX_Y + CELL / 2),
                 (MIN_X - CELL / 2, MIN_Y - CELL / 2)]:
        border.goto(x, y)
    border.penup()
    return screen


def inside_board(position):
    x, y = position
    return MIN_X <= x <= MAX_X and MIN_Y <= y <= MAX_Y
```

`Screen()` создаёт окно; `setup()` задаёт размеры; `bgcolor()` меняет фон; `title()` — заголовок. `tracer(0)` отключает автоматическую перерисовку, поэтому далее вызываем `screen.update()` вручную. Рамку рисует отдельная скрытая черепашка: `penup()` поднимает перо, `pendown()` опускает, `goto()` перемещает объект, а `hideturtle()` скрывает его значок, но не линию.

В Turtle начало координат `(0, 0)` находится в центре окна. X увеличивается вправо, Y — вверх. В этой игре центр клетки должен иметь X от −280 до 280 и Y от −280 до 240. Рамка проходит на 10 пикселей дальше крайних центров. Верх поля ниже верхнего края окна, чтобы осталось место для счёта.

```text
                  +Y
                   ↑
           счёт (зона вне поля)
        ┌─────────────────────┐
        │          │          │
  −X ←  │──────── (0,0) ──────│ → +X
        │          │          │
        └─────────────────────┘
                   ↓
                  −Y
```

Функция `inside_board()` возвращает `True`, если координаты центра находятся в допустимых границах. Всего на поле 29 столбцов и 27 строк (783 клетки).

### 1.3. В конец файла добавьте запускающий блок


```python
screen = create_screen()
screen.update()
screen.mainloop()
```

`mainloop()` запускает обработку событий окна (клавиатура, таймеры, закрытие). В файле он должен быть один и находиться после настройки объектов.

**Ожидаемый результат:** пустое тёмное окно с белой прямоугольной рамкой.

Измените заголовок, фон и цвет рамки. Затем объясните, почему `(0, 240)` внутри поля, а `(0, 260)` — нет. Подсказка: сравните Y с `MAX_Y`. Не изменяйте размер клетки и границы, пока не закончите базовый вариант.

## Этап 2. Создание класса Snake

### Что реализуем

Змейка состоит из нескольких квадратов Turtle, каждый квадрат — отдельный объект. Список хранит их в порядке от головы к хвосту: индекс 0 соответствует голове. Это удобно, потому что длина будет меняться, а к каждому сегменту можно обращаться по индексу.

### 2.1. Перед запускающим блоком (после функций) добавьте класс


```python
class Snake:
    def __init__(self):
        self._segments = []
        for position in START_POSITIONS:
            self._add_segment(position)
        self.get_head().color('#b7f7c5')

    def _add_segment(self, position):
        segment = turtle.Turtle('square')
        segment.penup()
        segment.speed(0)
        segment.color('#68d391')
        segment.goto(position)
        self._segments.append(segment)

    def get_head(self):
        return self._segments[0]
```

При создании `Snake()` конструктор подготавливает пустой список и вызывает `_add_segment()` для трёх начальных координат. `Turtle('square')` создаёт квадрат размером 20 × 20 в стандартном масштабе. `speed(0)` отключает анимацию перемещения самой черепашки, но не задаёт скорость игры. `append()` добавляет объект в конец списка. `get_head()` возвращает первый объект, а `_segments` и `_add_segment()` предназначены для внутренней работы класса (одинарное подчёркивание — соглашение, а не строгий запрет доступа).

### 2.2. Замените запускающий блок в конце файла


```python
screen = create_screen()
snake = Snake()
screen.update()
screen.mainloop()
```

**Ожидаемый результат:** три зелёных квадрата в центре поля, голова светлее тела. Их центры: `(0, 0)`, `(-20, 0)`, `(-40, 0)`.

### Попробуй самостоятельно

Увеличьте начальную длину до четырёх сегментов, добавив `(-3 * CELL, 0)` в `START_POSITIONS`. Измените цвет головы. Убедитесь, что сегменты расположены подряд без пропусков. Для остальных этапов можно вернуть исходную длину три.

## Этап 3. Движение змейки

### Что реализуем

Голова перемещается на одну клетку вправо, а каждый следующий сегмент занимает прежнее место предыдущего. Обновлять тело нужно **от хвоста к голове**. Иначе при переносе второго сегмента третий прочитает уже изменённую позицию, и части тела наложатся.

### 3.1. В `Snake.__init__()` после создания списка добавьте строку


```python
        self._direction = (CELL, 0)
```

Это вектор движения: `(dx, dy)`. Для направления вправо X увеличивается на 20, а Y не меняется.

### 3.2. В конец класса Snake добавьте методы


```python
    def next_position(self):
        dx, dy = self._direction
        return self.get_head().xcor() + dx, self.get_head().ycor() + dy

    def move(self):
        target = self.next_position()
        for index in range(len(self._segments) - 1, 0, -1):
            self._segments[index].goto(self._segments[index - 1].position())
        self.get_head().goto(target)
```

`next_position()` вычисляет следующую координату головы без перемещения. `xcor()` и `ycor()` возвращают текущие координаты. `position()` возвращает пару координат. `range(len(...) - 1, 0, -1)` перебирает индексы с конца до 1, не включая 0. После переноса тела `goto(target)` перемещает голову отдельно.

| Сегмент | До шага | После шага |
|---|---|---|
| Голова | `(0, 0)` | `(20, 0)` |
| Середина | `(-20, 0)` | `(0, 0)` |
| Хвост | `(-40, 0)` | `(-20, 0)` |

### 3.3. Замените весь запускающий блок


```python
screen = create_screen()
snake = Snake()


def tick():
    if not inside_board(snake.next_position()):
        print('Достигнута граница поля')
        return
    snake.move()
    screen.update()
    screen.ontimer(tick, START_DELAY)


screen.update()
screen.ontimer(tick, START_DELAY)
screen.mainloop()
```

`ontimer(tick, START_DELAY)` просит Turtle вызвать функцию через указанное число миллисекунд. Передаётся имя функции `tick`, а не `tick()`. Каждый вызов планирует следующий. Так окно остаётся доступным для клавиатуры и не требует блокирующего `while True` или `time.sleep()`. Временная проверка границы останавливает движение до выхода за рамку; полноценное завершение добавим позже.

**Ожидаемый результат:** змейка движется вправо примерно каждые 0,15 секунды и останавливается у правой границы. В консоли появляется сообщение «Достигнута граница поля».

Установите `START_DELAY = 250`, затем `START_DELAY = 80`. Сравните движение. Почему меньшее значение означает более быструю игру? Измените задержку, а не `CELL`, чтобы движение оставалось по сетке.

## Этап 4. Управление с клавиатуры

### Что реализуем

Четыре направления по стрелкам. Змейка, движущаяся вправо, не может сразу пойти влево: она столкнулась бы с соседним сегментом. Также нельзя разрешать два поворота между двумя игровыми шагами — иначе нажатия «вверх, влево» подряд позволят фактически развернуться назад.

### 4.1. В конструкторе Snake сразу после `_direction` добавьте


```python
        self._pending_direction = None
```

`_direction` хранит направление последнего фактического движения; `_pending_direction` — один ожидающий поворот. `None` означает, что поворот не запрошен.

### 4.2. Замените методы `next_position()` и `move()`


```python
    def next_position(self):
        direction = self._pending_direction or self._direction
        dx, dy = direction
        return self.get_head().xcor() + dx, self.get_head().ycor() + dy

    def move(self):
        target = self.next_position()
        if self._pending_direction is not None:
            self._direction = self._pending_direction
            self._pending_direction = None
        for index in range(len(self._segments) - 1, 0, -1):
            self._segments[index].goto(self._segments[index - 1].position())
        self.get_head().goto(target)
```

Если ожидающий поворот есть, следующая клетка рассчитывается по нему. В `move()` направление принимается, а очередь очищается. Выражение `a or b` здесь выбирает `a`, если оно не `None` (векторы представлены непустыми кортежами), иначе `b`.

### 4.3. В конец класса Snake добавьте методы


```python
    def _set_direction(self, direction):
        dx, dy = self._direction
        if direction == (-dx, -dy) or direction == self._direction:
            return
        # Не больше одного поворота между двумя шагами игры.
        if self._pending_direction is None:
            self._pending_direction = direction

    def up(self):
        self._set_direction((0, CELL))

    def down(self):
        self._set_direction((0, -CELL))

    def left(self):
        self._set_direction((-CELL, 0))

    def right(self):
        self._set_direction((CELL, 0))
```

`_set_direction()` запрещает противоположный и повторный запросы. Только первый допустимый поворот до следующего шага записывается в очередь. Методы `up()`, `down()`, `left()` и `right()` скрывают детали проверки: внешний код просто просит змейку повернуть.

### 4.4. В конце файла после `snake = Snake()` и до запуска таймера добавьте


```python
screen.listen()
screen.onkey(snake.up, 'Up')
screen.onkey(snake.down, 'Down')
screen.onkey(snake.left, 'Left')
screen.onkey(snake.right, 'Right')
```

`listen()` позволяет окну получать события клавиатуры. `onkey()` связывает функцию с отпусканием клавиши. Важно писать `snake.up`, а не `snake.up()`: метод должен выполняться при событии, а не во время настройки.

**Ожидаемый результат:** змейка перемещается в четырёх направлениях; противоположная стрелка не меняет курс. Если окно не реагирует, щёлкните по нему. После достижения стены пока нужно перезапустить файл.

## Этап 5. Создание класса Food

### Что реализуем

Добавим еду как отдельную черепашку. Вместо повторения всех методов Turtle класс `Food` наследует их и добавляет собственный метод `refresh()`.

### 5.1. После класса Snake, перед запускающим блоком, добавьте


```python
class Food(turtle.Turtle):
    def __init__(self):
        super().__init__('circle')
        self.penup()
        self.speed(0)
        self.color('#ff6b6b')
        self.shapesize(0.7, 0.7)
        self.hideturtle()

    def refresh(self):
        x = random.randrange(MIN_X, MAX_X + 1, CELL)
        y = random.randrange(MIN_Y, MAX_Y + 1, CELL)
        self.goto(x, y)
        self.showturtle()
```

`super().__init__('circle')` вызывает конструктор родительского класса `Turtle` и задаёт круглую форму. `shapesize(0.7, 0.7)` уменьшает значок примерно до 14 × 14 пикселей. `random.randrange(начало, конец, шаг)` выбирает случайное значение с указанным шагом; верхняя граница не включается, поэтому прибавляем 1. Позиции кратны размеру клетки, и змейка может точно попасть на еду. `showturtle()` делает объект видимым.

### 5.2. В запускающем блоке после `snake = Snake()` добавьте


```python
food = Food()
food.refresh()
```

**Ожидаемый результат:** на поле видна небольшая красная круглая еда. При повторном запуске она обычно появляется в другом месте. Пока есть вероятность появления на змейке, и столкновение ещё не обработано — это исправим на следующем этапе.

### Попробуй самостоятельно

Замените форму на `triangle`, цвет — на жёлтый. Затем вызовите `food.refresh()` несколько раз в отдельном проверочном запуске и напечатайте `food.position()`. Убедитесь, что координаты кратны 20 и внутри рамки. Верните исходную форму при желании.

## Этап 6. Обнаружение столкновения с едой

### Что реализуем

Когда голова оказывается на клетке еды, её нужно переместить. `distance()` вычисляет расстояние от одного объекта Turtle до другого. На нашей сетке расстояние меньше `CELL / 2` (10) означает попадание на одну клетку. Соседняя клетка находится на расстоянии 20.

### 6.1. В `tick()` сразу после `snake.move()` добавьте


```python
    if snake.get_head().distance(food) < CELL / 2:
        food.refresh()
```

Теперь проверка выполняется после каждого фактического перемещения. Пока змейка не растёт, а еда просто меняет координаты.

### Попробуй самостоятельно

Улучшите появление еды: она не должна попадать ни на голову, ни на любой сегмент тела. Подсказка: получите список занятых координат, переберите все клетки через два цикла `for`, затем выберите случайную свободную клетку. Что делать, если свободных клеток не осталось? Сначала попробуйте самостоятельно, затем сравните с вариантом ниже.

### 6.2. Проверочный вариант для продолжения проекта

В класс Snake добавьте:


```python
    def positions(self):
        return [segment.position() for segment in self._segments]
```

Метод возвращает новый список координат сегментов. Запись `[... for ... in ...]` — сокращение обычного цикла с `append()`; она не отдаёт наружу сам список объектов `_segments`.

В классе Food замените метод `refresh()` целиком:


```python
    def refresh(self, occupied=()):
        free_cells = []
        for x in range(MIN_X, MAX_X + 1, CELL):
            for y in range(MIN_Y, MAX_Y + 1, CELL):
                if (x, y) not in occupied:
                    free_cells.append((x, y))
        if not free_cells:
            self.hideturtle()
            return False
        self.goto(random.choice(free_cells))
        self.showturtle()
        return True
```

Два цикла создают список свободных клеток. `random.choice()` выбирает один элемент из списка. Аргумент `occupied=()` означает, что при отсутствии списка занятых клеток используется пустой кортеж. Если свободных клеток нет, метод скрывает еду и возвращает `False`; иначе возвращает `True`. Это исключает бесконечные попытки искать свободную позицию при заполненном поле.

В запускающем блоке и в `tick()` замените оба вызова `food.refresh()` на `food.refresh(snake.positions())`.

**Ожидаемый результат:** еда исчезает из съеденной клетки и появляется на свободной. Длина пока остаётся прежней. Для теста можно временно задать `food.goto(20, 0)` сразу после начального `refresh()` — при первом движении вправо еда будет съедена. После проверки удалите тестовую строку.

## Этап 7. Увеличение длины змейки

### Что реализуем

При поедании еды нужно добавить сегмент на позицию, которую хвост занимал **до текущего шага**. Если создать сегмент в новой позиции хвоста, он наложится на уже существующий квадрат.

### 7.1. Замените метод `move()` в классе Snake


```python
    def move(self):
        old_tail = self._segments[-1].position()
        target = self.next_position()
        if self._pending_direction is not None:
            self._direction = self._pending_direction
            self._pending_direction = None
        for index in range(len(self._segments) - 1, 0, -1):
            self._segments[index].goto(self._segments[index - 1].position())
        self.get_head().goto(target)
        return old_tail
```

Первая строка сохраняет старую координату хвоста. После перемещения метод возвращает её через `return`. Например, до шага хвост находился в `(-40, 0)`, после шага — в `(-20, 0)`; новый сегмент должен занять `(-40, 0)`.

```python
    def extend(self, position):
        self._add_segment(position)
```

Метод использует уже написанный `_add_segment()` — не нужно повторять создание и настройку Turtle.

## Этап 9. Столкновения и завершение игры

### Что реализуем

Проверка стены выполняется до движения головы. Проверка тела — после перемещения сегментов, но до обработки еды. Это важно: если голова попадает на прежнюю клетку хвоста, который уже освободил её на этом шаге, столкновения нет. Сравнение головы со всеми остальными текущими позициями обнаруживает реальное столкновение.

### 9.1. Добавьте в класс Snake


```python
    def hits_body(self):
        return self.get_head().position() in self.positions()[1:]
```

`self.positions()[1:]` — часть списка без первого элемента. Оператор `in` проверяет, совпадает ли позиция головы с позицией тела.

### 9.2. Добавьте в класс Scoreboard


```python
    def game_over(self, won=False):
        self.goto(0, 0)
        message = 'ПОБЕДА!' if won else 'GAME OVER'
        self.write(message, align='center', font=('Arial', 26, 'bold'))
        self.goto(0, -35)
        self.write('Нажми R для новой игры', align='center',
                   font=('Arial', 14, 'normal'))
```

Метод выводит сообщение в центре окна и подсказку о перезапуске. Он не очищает счёт. `won` имеет значение `False` по умолчанию; если еды больше негде разместить, можно передать `True` и показать победу.

### 9.3. Подготовьте Snake к сбросу состояния

Чтобы начать новый раунд, нужно вернуть три начальных сегмента и направление вправо. Не следует просто создавать новую змейку поверх старой: старые объекты останутся в окне. Используем список `_spares` для повторного использования скрытых сегментов.

Замените конструктор и `_add_segment()` следующими версиями, добавьте `reset()`; остальные методы Snake оставьте:


```python
    def __init__(self):
        self._segments = []
        self._spares = []
        self.reset()

    def _add_segment(self, position):
        # Повторно используем скрытые сегменты после перезапуска.
        if self._spares:
            segment = self._spares.pop()
        else:
            segment = turtle.Turtle('square')
            segment.penup()
            segment.speed(0)
        segment.color('#68d391')
        segment.goto(position)
        segment.showturtle()
        self._segments.append(segment)

    def reset(self):
        for segment in self._segments:
            segment.hideturtle()
            self._spares.append(segment)
        self._segments.clear()
        self._direction = (CELL, 0)
        self._pending_direction = None
        for position in START_POSITIONS:
            self._add_segment(position)
        self.get_head().color('#b7f7c5')
```

В `reset()` старые сегменты скрываются и помещаются в запас. `clear()` очищает список активных сегментов; `pop()` забирает последний элемент запаса. Когда запас пуст, создаётся новая черепашка. `showturtle()` возвращает использованный сегмент на экран. Направление и ожидающий поворот сбрасываются. Это позволяет многократно перезапускать игру без накопления новых объектов при каждом сбросе.

Подсказка: не вызывайте `ontimer()` внутри перезапуска, если игровой таймер уже запланирован. После попытки сверьтесь с полным временным блоком ниже.

### 9.4. Замените весь запускающий блок после классов

Здесь временно используется глобальная переменная `running`. На следующем этапе перенесём её в объект Game.


```python
screen = create_screen()
snake = Snake()
food = Food()
scoreboard = Scoreboard()
food.refresh(snake.positions())
running = True


def finish(won=False):
    global running
    running = False
    scoreboard.game_over(won)


def tick():
    if running:
        if not inside_board(snake.next_position()):
            finish()
        else:
            old_tail = snake.move()
            if snake.hits_body():
                finish()
            elif snake.get_head().distance(food) < CELL / 2:
                snake.extend(old_tail)
                scoreboard.increase_score()
                if not food.refresh(snake.positions()):
                    finish(won=True)
    screen.update()
    screen.ontimer(tick, START_DELAY)


def restart():
    global running
    if running:
        return
    snake.reset()
    scoreboard.reset()
    food.refresh(snake.positions())
    running = True
    screen.update()


screen.listen()
screen.onkey(snake.up, 'Up')
screen.onkey(snake.down, 'Down')
screen.onkey(snake.left, 'Left')
screen.onkey(snake.right, 'Right')
screen.onkey(snake.up, 'w')
screen.onkey(snake.down, 's')
screen.onkey(snake.left, 'a')
screen.onkey(snake.right, 'd')

screen.onkey(restart, 'R')

screen.update()
screen.ontimer(tick, START_DELAY)
screen.mainloop()
```

В `tick()` проверяем стену, перемещаем змейку, проверяем тело и только затем обрабатываем еду. Если `refresh()` вернул `False` после роста, поле заполнено и игрок победил. `finish()` меняет состояние на неактивное. Таймер продолжает срабатывать, но не двигает змейку, пока `running` равно `False`. `restart()` лишь сбрасывает состояние, не создавая дополнительной цепочки таймеров. `global running` нужен во временных функциях, которые присваивают новое значение глобальной переменной.

**Ожидаемый результат:** столкновение останавливает движение, появляется `GAME OVER`. После R старая змейка исчезает, появляется начальная из трёх сегментов, счёт равен нулю, рекорд сохраняется. Повторное нажатие R во время активной игры игнорируется.

## Этап 10. Создание класса Game

### Что реализуем

До сих пор игровые объекты и функции управления жили в основном коде файла. Теперь переносим управление в отдельный класс, чтобы хранить состояние через `self` и избавиться от глобальных переменных игрового процесса.

### 10.1. Удалите весь временный запускающий блок этапа 9

Оставьте импорты, константы, функции `create_screen()` и `inside_board()`, классы `Snake`, `Food`, `Scoreboard`. После них добавьте класс Game. Сначала конструктор и привязку клавиш:


```python
class Game:
    def __init__(self):
        self.screen = create_screen()
        self.snake = Snake()
        self.food = Food()
        self.scoreboard = Scoreboard()
        self.running = True
        self.delay = START_DELAY
        self.food.refresh(self.snake.positions())
        self.bind_keys()

    def bind_keys(self):
        self.screen.listen()
        for key, action in [('Up', self.snake.up), ('Down', self.snake.down),
                            ('Left', self.snake.left), ('Right', self.snake.right),
                            ('w', self.snake.up), ('s', self.snake.down),
                            ('a', self.snake.left), ('d', self.snake.right),
                            ('r', self.restart), ('R', self.restart)]:
            self.screen.onkey(action, key)
```

`Game` создаёт и хранит ссылки на три объекта: `self.snake`, `self.food`, `self.scoreboard`. `self.running` и `self.delay` — состояние данного экземпляра игры. В `bind_keys()` перебираются пары «клавиша, метод». Это сокращает повторяющиеся вызовы `onkey()`.

### 10.2. В этот же класс добавьте методы управления шагом


```python
    def finish(self, won=False):
        self.running = False
        self.scoreboard.game_over(won)

    def step(self):
        if not inside_board(self.snake.next_position()):
            self.finish()
            return
        old_tail = self.snake.move()
        if self.snake.hits_body():
            self.finish()
            return
        if self.snake.get_head().distance(self.food) < CELL / 2:
            self.snake.extend(old_tail)
            self.scoreboard.increase_score()
            if not self.food.refresh(self.snake.positions()):
                self.finish(won=True)

    def tick(self):
        if self.running:
            self.step()
        self.screen.update()
        # Единственная цепочка таймеров, даже после проигрыша.
        self.screen.ontimer(self.tick, self.delay)
```

`step()` выполняет ровно один шаг и не планирует таймер. `tick()` вызывает его только при активной игре, обновляет экран и планирует следующий вызов. Это разделение удобно для тестирования: можно отдельно проверить один шаг движения. `return` после столкновения не позволяет начислить очки после проигрыша.

### 10.3. В конец Game добавьте перезапуск и запуск


```python
    def restart(self):
        if self.running:
            return
        # Один интерфейс reset(), но разное поведение у объектов.
        for component in (self.snake, self.scoreboard):
            component.reset()
        self.food.refresh(self.snake.positions())
        self.delay = START_DELAY
        self.running = True
        self.screen.update()

    def start(self):
        self.screen.update()
        self.screen.ontimer(self.tick, self.delay)
        self.screen.mainloop()
```

`restart()` использует общий метод `reset()` двух разных объектов. Змейка сбрасывает тело и направление, а таблица счёта — очки и надпись. Это естественный пример полиморфизма: один вызов, разная реализация. Затем еда размещается заново. Рекорд не сбрасывается. `start()` запускает единственную цепочку таймеров и обработку событий.

### 10.4. В самом конце файла вне классов добавьте


```python
if __name__ == '__main__':
    Game().start()
```

Условие означает, что игра запускается при прямом запуске файла, но не при его импорте. Это пригодится при разделении проекта на модули. В конце программы больше не должно остаться прежних глобальных `tick()`, `restart()` и дополнительных вызовов `mainloop()`.

**Ожидаемый результат:** игра запускается и работает так же, как на предыдущем этапе, но весь процесс управляется объектом Game. В конце основного файла всего две строки запуска.

### Попробуй самостоятельно

Добавьте паузу и продолжение по пробелу. Подсказка:

| Принцип | Где применяется | Зачем |

| Инкапсуляция | `Snake._segments`, `_direction`, `_spares`, методы `move()`, `extend()`, `reset()`; изменение счёта через методы | Не нужно изменять внутреннее состояние из Game. Подчёркивание — соглашение о внутреннем использовании. |
| Наследование | `Food(turtle.Turtle)` и `Scoreboard(turtle.Turtle)` | Повторно используем `goto()`, `color()`, `write()` и другие готовые методы. `super()` инициализирует родительскую часть объекта. |
| Полиморфизм | `component.reset()` для Snake и Scoreboard в `Game.restart()` | Одинаковый интерфейс, разные действия; общий родитель для этих двух классов не нужен. |
| Абстракция | `self.snake.move()`, `self.food.refresh(...)`, `self.scoreboard.increase_score()` | Game знает, какую операцию запросить, но не обязан знать алгоритм движения, выбора клетки или вывода текста. |

`Game` содержит объекты других классов — это композиция. Он не является разновидностью Snake, Food или Scoreboard, поэтому наследование здесь не требуется. Game координирует объекты, а не подменяет их методы.

## Распространённые ошибки и способы проверки

| Проблема | Возможная причина | Что проверить |

| Пустое окно | `tracer(0)` без `update()` | Обновление экрана при старте и в таймере |

## Полный итоговый исходный код

Используйте этот вариант для проверки **после самостоятельного прохождения этапов**. Скопируйте его целиком в `main.py` только если хотите запустить эталон отдельно. Он включает основные возможности, WASD, рекорд текущего запуска, перезапуск и победу. Пауза, сохранение рекорда на диск и остальные улучшения этапа 11 оставлены для самостоятельного выполнения.


```python
import random
import turtle

CELL = 20
MIN_X, MAX_X = -280, 280
MIN_Y, MAX_Y = -280, 240
START_DELAY = 150
START_POSITIONS = [(0, 0), (-CELL, 0), (-2 * CELL, 0)]


def create_screen():
    screen = turtle.Screen()
    screen.setup(640, 640)
    screen.title('Змейка — Python Turtle')
    screen.bgcolor('#17212b')
    screen.tracer(0)

    # Рамка проходит по внешним краям игровых клеток.
    border = turtle.Turtle()
    border.hideturtle()
    border.speed(0)
    border.color('white')
    border.penup()
    border.goto(MIN_X - CELL / 2, MIN_Y - CELL / 2)
    border.pendown()
    for x, y in [(MAX_X + CELL / 2, MIN_Y - CELL / 2),
                 (MAX_X + CELL / 2, MAX_Y + CELL / 2),
                 (MIN_X - CELL / 2, MAX_Y + CELL / 2),
                 (MIN_X - CELL / 2, MIN_Y - CELL / 2)]:
        border.goto(x, y)
    border.penup()
    return screen


def inside_board(position):
    x, y = position
    return MIN_X <= x <= MAX_X and MIN_Y <= y <= MAX_Y


class Snake:
    def __init__(self):
        self._segments = []
        self._spares = []
        self.reset()

    def _add_segment(self, position):
        # Повторно используем скрытые сегменты после перезапуска.
        if self._spares:
            segment = self._spares.pop()
        else:
            segment = turtle.Turtle('square')
            segment.penup()
            segment.speed(0)
        segment.color('#68d391')
        segment.goto(position)
        segment.showturtle()
        self._segments.append(segment)

    def get_head(self):
        return self._segments[0]

    def positions(self):
        return [segment.position() for segment in self._segments]

    def reset(self):
        for segment in self._segments:
            segment.hideturtle()
            self._spares.append(segment)
        self._segments.clear()
        self._direction = (CELL, 0)
        self._pending_direction = None
        for position in START_POSITIONS:
            self._add_segment(position)
        self.get_head().color('#b7f7c5')

    def next_position(self):
        direction = self._pending_direction or self._direction
        dx, dy = direction
        return self.get_head().xcor() + dx, self.get_head().ycor() + dy

    def move(self):
        old_tail = self._segments[-1].position()
        target = self.next_position()
        if self._pending_direction is not None:
            self._direction = self._pending_direction
            self._pending_direction = None
        for index in range(len(self._segments) - 1, 0, -1):
            self._segments[index].goto(self._segments[index - 1].position())
        self.get_head().goto(target)
        return old_tail

    def _set_direction(self, direction):
        dx, dy = self._direction
        if direction == (-dx, -dy) or direction == self._direction:
            return
        # Не больше одного поворота между двумя шагами игры.
        if self._pending_direction is None:
            self._pending_direction = direction

    def up(self):
        self._set_direction((0, CELL))

    def down(self):
        self._set_direction((0, -CELL))

    def left(self):
        self._set_direction((-CELL, 0))

    def right(self):
        self._set_direction((CELL, 0))

    def extend(self, position):
        self._add_segment(position)

    def hits_body(self):
        return self.get_head().position() in self.positions()[1:]


class Food(turtle.Turtle):
    def __init__(self):
        super().__init__('circle')
        self.penup()
        self.speed(0)
        self.color('#ff6b6b')
        self.shapesize(0.7, 0.7)
        self.hideturtle()

    def refresh(self, occupied=()):
        free_cells = []
        for x in range(MIN_X, MAX_X + 1, CELL):
            for y in range(MIN_Y, MAX_Y + 1, CELL):
                if (x, y) not in occupied:
                    free_cells.append((x, y))
        if not free_cells:
            self.hideturtle()
            return False
        self.goto(random.choice(free_cells))
        self.showturtle()
        return True


class Scoreboard(turtle.Turtle):
    def __init__(self):
        super().__init__()
        self.hideturtle()
        self.penup()
        self.speed(0)
        self.color('white')
        self.score = 0
        self.high_score = 0
        self.reset()

    def update_score(self):
        self.clear()
        self.goto(0, 265)
        self.write(f'Счёт: {self.score}   Рекорд: {self.high_score}',
                   align='center', font=('Arial', 16, 'normal'))

    def increase_score(self):
        self.score += 1
        if self.score > self.high_score:
            self.high_score = self.score
        self.update_score()

    def reset(self):
        self.score = 0
        self.update_score()

    def game_over(self, won=False):
        self.goto(0, 0)
        message = 'ПОБЕДА!' if won else 'GAME OVER'
        self.write(message, align='center', font=('Arial', 26, 'bold'))
        self.goto(0, -35)
        self.write('Нажми R для новой игры', align='center',
                   font=('Arial', 14, 'normal'))


class Game:
    def __init__(self):
        self.screen = create_screen()
        self.snake = Snake()
        self.food = Food()
        self.scoreboard = Scoreboard()
        self.running = True
        self.delay = START_DELAY
        self.food.refresh(self.snake.positions())
        self.bind_keys()

    def bind_keys(self):
        self.screen.listen()
        for key, action in [('Up', self.snake.up), ('Down', self.snake.down),
                            ('Left', self.snake.left), ('Right', self.snake.right),
                            ('w', self.snake.up), ('s', self.snake.down),
                            ('a', self.snake.left), ('d', self.snake.right),
                            ('r', self.restart), ('R', self.restart)]:
            self.screen.onkey(action, key)

    def finish(self, won=False):
        self.running = False
        self.scoreboard.game_over(won)

    def step(self):
        if not inside_board(self.snake.next_position()):
            self.finish()
            return
        old_tail = self.snake.move()
        if self.snake.hits_body():
            self.finish()
            return
        if self.snake.get_head().distance(self.food) < CELL / 2:
            self.snake.extend(old_tail)
            self.scoreboard.increase_score()
            if not self.food.refresh(self.snake.positions()):
                self.finish(won=True)

    def tick(self):
        if self.running:
            self.step()
        self.screen.update()
        # Единственная цепочка таймеров, даже после проигрыша.
        self.screen.ontimer(self.tick, self.delay)

    def restart(self):
        if self.running:
            return
        # Один интерфейс reset(), но разное поведение у объектов.
        for component in (self.snake, self.scoreboard):
            component.reset()
        self.food.refresh(self.snake.positions())
        self.delay = START_DELAY
        self.running = True
        self.screen.update()

    def start(self):
        self.screen.update()
        self.screen.ontimer(self.tick, self.delay)
        self.screen.mainloop()


if __name__ == '__main__':
    Game().start()
```

**Итог:** игра построена на четырёх взаимодействующих классах. Изменение одной части программы (например, оформления еды) не требует переписывать остальные. Главный класс связывает компоненты через методы, а игровой цикл работает через события Turtle.
