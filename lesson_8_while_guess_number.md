# Практическое задание: Игра «Угадай число»

## Исходный код без цикла

```python
secret = 17

number = int(input("Угадайте число от 1 до 100: "))

if number == secret:
    print("Поздравляем! Вы угадали!")
elif number < secret:
    print("Загаданное число больше!")
else:
    print("Загаданное число меньше!")

print("Игра окончена!")
```

## Задание для студентов

Доработайте готовую игру с помощью цикла `while`.

### Требования

1. Пользователь должен угадывать число до победы.
2. После неправильного ответа программа должна давать подсказку «Больше» или «Меньше».
3. Подсчитывайте количество попыток.
4. После правильного ответа выведите количество использованных попыток.
5. **Дополнительно:** ограничьте количество попыток до 7. Если число не угадано, выведите «Вы проиграли!».
