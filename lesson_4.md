# 1. Повторение: `print()`

Мы уже знаем, что `print()` выводит информацию на экран.

Пример:

```python

print("Python")
print(123)
```

Также можно выводить сразу несколько значений:

```python

age = 17

print("Возраст:", age)
```

# 2. Аргумент `sep`

`sep` означает **разделитель**.

Когда мы передаём несколько значений в `print()`, Python по умолчанию ставит между ними пробел:

```python
print("Python", "Java", "C++")
```

Этот разделитель можно изменить с помощью `sep`:

```python
print("Python", "Java", "C++", sep=" | ")
```

Ещё примеры:

```python
print(6, 10, 2026, sep="-")
print(192, 168, 1, 10, sep=".")
print("home", "student", "python", sep="/")
```

# 3. Аргумент `end`

По умолчанию каждый `print()` заканчивается переходом на новую строку:

```python
print("Привет")
print("Мир")
```

Мы можем изменить то, что происходит **после** `print()`, с помощью `end`.

Например:

```python
print("Привет", end=" ")
print("Мир")
```

Ещё один пример:

```python
print("Загрузка", end="")
print(".", end="")
print(".", end="")
print(".")
```

# 6. Операторы сравнения

Python умеет сравнивать значения.

Результат сравнения всегда один из двух:

- `True`
- `False`

Основные операторы сравнения:

| Оператор | Значение |
|---|---|
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |
| `==` | равно |
| `!=` | не равно |

```python
print(10 > 5)
print(10 < 5)
print(10 == 10)
print(10 != 5)
print(7 >= 7)
print(3 <= 2)
```

## Важно: `=` и `==` — это разные операторы

`=` означает **присваивание**.

`==` означает **сравнение**.

```python
x = 10

print(x)
print(x == 10)
print(x == 5)
```

# 7. Первый `if` statement

Теперь мы знаем, как получить `True` или `False`.

Следующий вопрос:

> Может ли Python выполнить код **только тогда, когда условие истинно**?

Да — с помощью `if`.

Структура:

```python
if condition:
    code
```

Код с отступом относится к блоку `if`.

```python
age = int(input("Введите возраст: "))

if age >= 18:
    print("Доступ разрешён")
```

Попробуйте запустить пример несколько раз:

- возраст = `20`
- возраст = `18`
- возраст = `15`

Обратите внимание: если условие равно `False`, код внутри `if` не выполняется.

# 8. `if / else`

Иногда нужно выполнить одно действие, если условие истинно, и другое — если оно ложно.

Структура:

```python
if condition:
    action_if_true
else:
    action_if_false
```

```python
age = int(input("Введите возраст: "))

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Логику можно представить так:

```text
            age >= 18?
             /      \
          True      False
           /           \
    Доступ разрешён   Доступ запрещён
```

# 9. Практический пример — Проверка пароля

Этот пример хорошо показывает, зачем нужны условия.

Программа должна вести себя по-разному в зависимости от введённых данных.

```python
password = input("Введите пароль: ")

if password == "python123":
    print("Вход выполнен")
else:
    print("Неверный пароль")
```

Попробуйте:

```text

```

Затем попробуйте:

```text
hello
```

Программа выдаёт разные результаты благодаря условию.

## Упражнение 10 — Скидка

Магазин предоставляет **скидку 10%**, если сумма покупки составляет `5000` или больше.

Запросите у пользователя сумму покупки.

Если сумма не меньше `5000`, рассчитайте и выведите цену со скидкой.

Иначе выведите исходную цену.

```python
price = float(input("Введите сумму покупки: "))

# Напишите решение ниже
```

### Решение для преподавателя

```python
price = float(input("Введите сумму покупки: "))

    final_price = price * 0.9

    print("Итоговая цена:", final_price)
else:
    print("Скидки нет")
    print("Итоговая цена:", price)
```

# 11. Итоговый мини-проект — Простой банкомат

На счёте пользователя находится `5000`.

Запросите, сколько денег пользователь хочет снять.

Если запрошенная сумма меньше или равна балансу:

- выведите `Операция выполнена`;
- выведите оставшийся баланс.

Иначе:

- выведите `Недостаточно средств`.

```python
balance = 5000
amount = int(input("Сколько хотите снять? "))

# Напишите решение ниже
```

### Решение для преподавателя

```python
balance = 5000
amount = int(input("Сколько хотите снять? "))

if amount <= balance:
    print("Операция выполнена")
    print("Остаток:", balance - amount)
else:
    print("Недостаточно средств")
```

# 12. Почему `if / else` так важны?

Без условий программа всегда выполняет один и тот же набор действий.

С условиями программа может реагировать на разные ситуации.

Например:

```text
Пользователь вводит данные
       ↓
Программа проверяет условие
       ↓
   True / False
     ↙     ↘
Действие A  Действие B
```

Это основа принятия решений в программах.
