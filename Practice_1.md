# Домашнее задание по Python

**Тема:** Повторение основ Python: условия, циклы, строки и списки.

**Цель:** закрепить умение самостоятельно анализировать задачу и
выбирать подходящие конструкции Python.

**Время:** ориентировочно 50--70 минут.

## Правила выполнения

-   Решите все 8 заданий самостоятельно.
-   Для каждого задания создайте отдельный файл Python.
-   Используйте только изученные конструкции.
-   **Запрещены:** пользовательские функции (`def`), вложенные циклы,
    сложные алгоритмы.
-   Проверяйте результат программы на нескольких примерах.

------------------------------------------------------------------------

## Задание 1. Большее число

Напишите программу, которая запрашивает два целых числа и выводит
большее из них. Если числа равны, выведите `Числа равны`.

**Пример:**

``` text
Первое число: 8
Второе число: 12
Большее число: 12
```

## Задание 2. Оценка за контрольную

Напишите программу, которая запрашивает количество баллов от 0 до 100 и
выводит оценку:

-   80--100 --- `Отлично`.
-   60--79 --- `Хорошо`.
-   40--59 --- `Удовлетворительно`.
-   0--39 --- `Неудовлетворительно`.

Считайте, что пользователь вводит число от 0 до 100.

**Пример:**

``` text
Введите баллы: 72
Хорошо
```

## Задание 3. Числа, кратные трём

Напишите программу, которая запрашивает положительное целое число `N` и
выводит все числа от 1 до `N` включительно, которые делятся на 3 без
остатка.

**Пример:**

``` text
Введите N: 12
3 6 9 12
```

## Задание 4. Сумма нечётных чисел

Напишите программу, которая запрашивает положительное целое число `N` и
вычисляет сумму всех нечётных чисел от 1 до `N` включительно.

**Пример:**

``` text
Введите N: 7
Сумма нечётных чисел: 16
```

## Задание 5. Счётчик введённых чисел

Напишите программу, которая запрашивает целые числа до тех пор, пока
пользователь не введёт `0`. После этого выведите количество введённых
**ненулевых** чисел.

**Пример:**

``` text
Введите число: 5
Введите число: 9
Введите число: -2
Введите число: 0
Количество введённых чисел: 3
```

## Задание 6. Работа со словом

Напишите программу, которая запрашивает слово и выводит:

1.  Слово заглавными буквами.
2.  Количество символов в слове.
3.  Первую букву слова.
4.  Последнюю букву слова.

Считайте, что пользователь вводит непустое слово.

**Пример:**

``` text
Введите слово: python
Заглавными буквами: PYTHON
Количество символов: 6
Первая буква: p
Последняя буква: n
```

## Задание 7. Числа, которые делятся на 5

Дан список:

``` python
numbers = [10, 7, 25, 13, 40, 8, 15]
```

Напишите программу, которая перебирает список и выводит только числа,
делящиеся на 5 без остатка.

**Ожидаемый результат:**

``` text
10
25
40
15
```

## Задание 8. Анализ списка

Дан список:

``` python
numbers = [6, -3, 8, -1, 4, -5, 2]
```

Напишите программу, которая:

1.  Вычисляет сумму всех положительных чисел.
2.  Подсчитывает количество отрицательных чисел.
3.  Находит самое маленькое число в списке.

**Ожидаемый результат:**

``` text
Сумма положительных: 20
Количество отрицательных: 3
Минимальное число: -5
```

**Ограничение:** не используйте готовые функции `sum()` и `min()`.
