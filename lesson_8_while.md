**Тема:** Цикл `while`. Операторы `break`, `continue`, конструкция `while ... else`.

**Продолжительность:** 90 минут.

## 1. Знакомство с циклом `while`

### 1.1. Повторение цикла `for`

Ранее мы использовали цикл `for` для повторения действий.

**Пример 1. Вывод чисел от 1 до 5**

```python
for i in range(1, 6):
    print(i)
```

Результат:

```text
1
2
3
4
5
```

Тот же результат можно получить с помощью `while`.

**Пример 2. Использование `while`**

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

Цикл `while` выполняет блок команд, пока указанное условие истинно (`True`).

Общий синтаксис:

```python
while условие:
    # Команды, которые повторяются
```

### 1.2. Как работает цикл

Рассмотрим программу:

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

На каждой итерации проверяется условие `i <= 5`.

| Итерация | Значение `i` перед проверкой | Условие `i <= 5` | Действие |
|---|---|---|---|
| 1 | 1 | True | Вывод 1 |
| 2 | 2 | True | Вывод 2 |
| 3 | 3 | True | Вывод 3 |
| 4 | 4 | True | Вывод 4 |
| 5 | 5 | True | Вывод 5 |
| 6 | 6 | False | Завершение цикла |

## 2. Условия выполнения цикла

### 2.1. Бесконечный цикл

Если условие цикла всегда истинно, цикл может выполняться бесконечно.

**Пример 3. Бесконечный цикл**

```python
i = 1

while i <= 5:
    print(i)
```

Переменная `i` никогда не изменяется, поэтому условие `i <= 5` остаётся истинным.

Чтобы остановить такую программу в терминале, используйте `Ctrl + C`.

### 2.2. Цикл с изначально ложным условием

**Пример 4. Цикл, который не выполнится**

```python
i = 10

while i < 5:
    print(i)

print("Программа завершена")
```

Если условие изначально ложно (`False`), тело цикла не выполняется ни разу.

### 2.3. Проверка пользовательского ввода

Цикл `while` часто используется, когда нужно повторять запрос данных до получения правильного значения.

**Пример 5. Проверка возраста**

```python
age = int(input("Введите возраст: "))

while age < 1 or age > 120:
    print("Некорректный возраст!")
    age = int(input("Введите возраст: "))

print("Ваш возраст:", age)
```

Пример работы:

```text
Введите возраст: -5
Некорректный возраст!
Введите возраст: 200
Некорректный возраст!
Введите возраст: 19
Ваш возраст: 19
```

## 3. Практическое применение `while`

### 3.1. Ввод пароля

**Пример 6. Проверка пароля**

```python
password = input("Введите пароль: ")

while password != "1234":
    print("Неверный пароль!")
    password = input("Попробуйте снова: ")

print("Доступ разрешён")
```

Цикл повторяется до тех пор, пока пользователь не введёт правильный пароль.

### 3.2. Подсчёт стоимости покупок

**Пример 7. Касса магазина**

Пользователь вводит стоимость товаров. Ввод числа 0 завершает ввод.

```python
total = 0

price = int(input("Стоимость товара: "))

while price != 0:
    total += price
    price = int(input("Стоимость товара: "))

print("Итого к оплате:", total)
```

Пример работы:

```text
Стоимость товара: 150
Стоимость товара: 200
Стоимость товара: 350
Стоимость товара: 0

Итого к оплате: 700
```

### 3.3. Игра «Угадай число»

**Пример 8. Поиск загаданного числа**

```python
secret = 17

guess = int(input("Угадайте число: "))

while guess != secret:
    if guess < secret:
        print("Загаданное число больше")
    else:
        print("Загаданное число меньше")

    guess = int(input("Попробуйте ещё: "))

print("Вы угадали!")
```

## 4. Бесконечный цикл `while True` и оператор `break`

### 4.1. Конструкция `while True`

Иногда программа должна непрерывно повторять действие, пока пользователь явно не попросит завершить работу.

Для этого можно использовать:

```python
while True:
    # Повторяющиеся команды
```

### 4.2. Оператор `break`

`break` немедленно завершает выполнение ближайшего цикла.

**Пример 9. Завершение по команде**

```python
while True:
    number = int(input("Введите число: "))

    if number == 0:
        break

    print("Вы ввели:", number)

print("Программа завершена")
```

### 4.3. Практический пример: меню программы

**Пример 10. Простое меню**

```python
while True:
    print("1. Начать игру")
    print("2. Настройки")
    print("0. Выход")

    choice = input("Выберите действие: ")

    if choice == "0":
        print("До свидания!")
        break

    print("Вы выбрали:", choice)
```

### 4.4. Ограничение количества попыток

**Пример 11. Проверка PIN-кода**

```python
pin = "1234"
attempts = 0

while attempts < 3:
    entered = input("Введите PIN-код: ")

    if entered == pin:
        print("Доступ разрешён")
        break

    attempts += 1
    print("Неверный PIN-код")

print("Проверка завершена")
```

## 5. Оператор `continue`

Оператор `continue` пропускает оставшиеся команды текущей итерации и переходит к следующей проверке условия цикла.

В отличие от `break`, он не завершает весь цикл.

### 5.1. Пропуск определённого числа

**Пример 12. Пропускаем число 5**

```python
i = 0

while i < 10:
    i += 1

    if i == 5:
        continue

    print(i)
```

Результат:

```text
1
2
3
4
6
7
8
9
10
```

Важно: при использовании `continue` необходимо следить за изменением переменных, от которых зависит условие цикла.

### 5.2. Пропуск отрицательных чисел

**Пример 13. Сумма только положительных чисел**

```python
total = 0

while True:
    number = int(input("Введите число: "))

    if number == 0:
        break

    if number < 0:
        continue

    total += number

print("Сумма положительных:", total)
```

## 6. Конструкция `while ... else`

После цикла `while` можно использовать блок `else`.

Блок `else` выполняется, если цикл завершился без использования `break`.

### 6.1. Обычное завершение цикла

**Пример 14. `while` с `else`**

```python
i = 1

while i <= 5:
    print(i)
    i += 1
else:
    print("Цикл завершился нормально")
```

### 6.2. Завершение с помощью `break`

**Пример 15. `else` не выполняется**

```python
i = 1

while i <= 5:
    if i == 3:
        break

    print(i)
    i += 1
else:
    print("Цикл завершился нормально")

print("Конец программы")
```

### 6.3. Поиск числа

**Пример 16. Поиск заданного числа за 5 попыток**

```python
attempts = 0

while attempts < 5:
    number = int(input("Введите число: "))

    if number == 7:
        print("Число найдено!")
        break

    attempts += 1
else:
    print("Число 7 не найдено")
```
