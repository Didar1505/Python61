## Поиск логических ошибок в Python

**Цель:** научиться находить ошибки в программах, которые запускаются без синтаксических ошибок, но работают неправильно.

**Что уже можно использовать:** переменные, арифметические операции, `print()`, `input()`, `int()`, `float()`, `if`, `elif`, `else`, логические операторы, `for` и `range()`.

**Ограничения:** не использовать вложенные циклы, `while`, списки, словари, собственные функции и `break`.

### Инструкция

В каждой программе содержится **от 2 до 5 логических ошибок**. Код синтаксически корректен. Для каждого задания:

1. Прочитайте описание и определите ожидаемое поведение программы.
2. Найдите неверные строки, не запуская код.
3. Исправьте программу, не изменяя её назначение.
4. Запустите её и проверьте на примере из задания.
5. Объясните, почему исходная версия работала неправильно.

**Важно:** в заданиях намеренно не отмечены строки с ошибками. Правильные решения не приводятся.

## Задание 1. Чётное или нечётное

**Описание:** пользователь вводит положительное число `N`. Программа должна вывести все числа от `1` до `N` включительно и подписать каждое: «чётное» или «нечётное».

**Проверка:** при `N = 4` последняя строка должна быть `4 чётное`.

```python
n = int(input("Введите N: "))

for number in range(1, n):
    if number % 2 == 1:
        print(number, "чётное")
    else:
        print(number, "нечётное")
```

## Задание 2. Обратный отсчёт

**Описание:** пользователь вводит положительное число `N`. Программа должна вывести числа от `N` до `1`, затем **один раз** напечатать «Старт!».

**Проверка:** при `N = 3` вывод должен быть `3`, `2`, `1`, `Старт!` — по одной строке.

```python
n = int(input("Введите N: "))

for i in range(n, 0, -1):
    print(i + 1)
    print("Старт!")
```

## Задание 3. Таблица умножения

**Описание:** пользователь вводит число. Программа должна вывести произведения этого числа на `1`, `2`, `3`, `4`, `5`.

**Проверка:** для числа `4` последняя строка должна быть `4 x 5 = 20`.

```python
number = int(input("Введите число: "))

for i in range(1, 5):
    result = number + i
    print(number, "x", i, "=", result)
```

## Задание 4. Сумма и чётные числа

**Описание:** пользователь вводит положительное число `N`. Программа должна посчитать сумму чисел от `1` до `N` и количество чётных чисел в этом диапазоне.

**Проверка:** при `N = 5` сумма равна `15`, количество чётных — `2`.

```python
n = int(input("Введите N: "))
total = 1
even_count = 0

for number in range(1, n + 1):
    total = total + number
    if number % 2 != 0:
        even_count = even_count + 1

print("Сумма:", total)
print("Чётных чисел:", even_count + 1)
```

## Задание 5. Выигрышные билеты

**Описание:** каждый посетитель вводит положительный номер билета. Билет выигрышный, только если его номер делится **одновременно на 3 и на 7**. Программа должна вывести результат для каждого билета и общее количество выигрышных.

**Проверка:** билеты `14`, `21`, `42`, `15` дают ровно `2` выигрыша.

```python
n = int(input("Количество посетителей: "))
wins = 0

for i in range(1, n + 1):
    ticket = int(input("Номер билета: "))
    if ticket % 3 == 0 or ticket % 7 == 0:
        print("Выигрыш!")
        wins = wins + 2
    else:
        print("Нет выигрыша")

print("Всего выигрышей:", wins)
```

## Задание 6. Скидки в магазине

**Описание:** пользователь вводит количество товаров и цену каждого. Если цена меньше `500`, скидки нет; от `500` до `999.99` — скидка `5%`; от `1000` и выше — `10%`. Программа должна показать цену после скидки и **общую сумму всех товаров**.

**Проверка:** товары по `300`, `800` и `1500` рублей должны стоить после скидок `300`, `760`, `1350`; итог — `2410` рублей. Проверьте также цену ровно `1000` рублей.

```python
n = int(input("Количество товаров: "))
total = 0

for i in range(n):
    price = float(input("Цена товара: "))

    if price > 1000:
        price = price * 0.95
    elif price >= 500:
        price = price * 0.90

    print("После скидки:", price)
    total = price

print("Итого:", total)
```

## Задание 7. Робот на прямой

**Описание:** робот начинает в точке `0`. Каждая команда — число: положительное перемещает робота вправо, отрицательное — влево. После каждой команды программа выводит позицию, а в конце сообщает, где робот: слева, справа или в начальной точке.

**Проверка:** команды `5`, `-2`, `-3` должны вернуть робота в точку `0`.

```python
n = int(input("Количество команд: "))
position = 0

for i in range(n):
    move = int(input("Команда: "))
    position = position - move
    print("Позиция:", position)

if position >= 0:
    print("Робот справа")
else:
    print("Робот слева")
```

## Задание 8. Электронное голосование

**Описание:** участники вводят `1` за первого кандидата, `2` — за второго. Все остальные значения — недействительные голоса. Программа должна правильно подсчитать три категории и определить победителя, в том числе обработать ничью.

**Проверка:** при голосах `1`, `2`, `2`, `3` должен победить второй кандидат; недействительный голос — один.

```python
n = int(input("Количество участников: "))
first = 0
second = 0
invalid = 0

for i in range(n):
    vote = int(input("Ваш голос: "))
    if vote == 1:
        first = first + 1
    elif vote == 2:
        first = first + 1
    else:
        invalid = invalid + 2

print("Первый:", first)
print("Второй:", second)
print("Недействительных:", invalid)

if first >= second:
    print("Победил первый кандидат")
else:
    print("Победил второй кандидат")
```

total = 0

for day in range(1, n + 1):

## Задание 10. PIN-код

**Описание:** правильный PIN — `4321`. Пользователь может сделать не больше трёх попыток. После правильного PIN программа больше не должна запрашивать ввод. После трёх неудач вывести «Карта заблокирована». **Оператор `break` не использовать.**

**Проверка:** если правильный PIN введён со второй попытки, третьего запроса быть не должно и блокировки тоже.

```python
correct_pin = 4321
guessed = False

for attempt in range(1, 4):
    if guessed == False:
        pin = int(input("Введите PIN: "))
        if pin == correct_pin:
            guessed = False
            print("Доступ разрешён")
        else:
            print("Неверный PIN. Осталось попыток:", 4 - attempt)

if guessed == False:
    print("Карта заблокирована")
```

## Задание 11. Оценки группы

**Описание:** пользователь вводит количество студентов и оценки от `2` до `5`. Программа должна определить, сколько получено пятёрок, и вычислить средний балл группы.

**Проверка:** оценки `5`, `4`, `2`, `5` означают `2` пятёрки и средний балл `4.0`.

```python
n = int(input("Количество студентов: "))
total = 1
fives = 0

for i in range(n):
    grade = int(input("Оценка: "))
    total = total + grade
    if grade >= 4:
        fives = fives + 1

average = total / (n + 1)
print("Пятёрок:", fives)
print("Средний балл:", average)
```

## Задание 12. FizzBuzz

**Описание:** для чисел от `1` до `N` программа должна вывести `Fizz` вместо кратных `3`, `Buzz` вместо кратных `5`, `FizzBuzz` вместо кратных одновременно `3` и `5`; остальные числа печатаются без изменений.

**Проверка:** при `N = 16` на месте `15` должно быть `FizzBuzz`, а первым результатом — `1`.

```python
n = int(input("Введите N: "))

for number in range(1, n + 1):
    if number % 3 == 0:
        print("Fizz")
    elif number % 5 == 0:
        print("Buzz")
    elif number % 3 == 0 and number % 5 == 0:
        print("FizzBuzz")
    else:
        print(number + 1)
```
