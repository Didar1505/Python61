# Практическое занятие № 2. Повторение основ Python

## Часть 1. Простые задачи на повторение (80 минут)

### Задание 1. Скидка в магазине

Пользователь вводит стоимость покупки. Если сумма составляет **1000
рублей или больше**, магазин предоставляет скидку **10%**. В противном
случае скидки нет.

Напишите программу, которая выводит итоговую стоимость покупки.

**Пример:**

``` text
Введите сумму покупки: 1500
Итоговая стоимость: 1350
```

### Задание 2. Подсчёт положительных чисел

Пользователь последовательно вводит **5 целых чисел**. Напишите
программу, которая подсчитывает, сколько среди них положительных.

**Пример:**

``` text
Введите число: 5
Введите число: -2
Введите число: 8
Введите число: 0
Введите число: 3
Положительных чисел: 3
```

### Задание 3. Сумма до нуля

Пользователь вводит целые числа. Программа должна складывать их до тех
пор, пока пользователь не введёт **0**. После этого выведите сумму
введённых чисел.

**Пример:**

``` text
Введите число: 5
Введите число: 10
Введите число: -3
Введите число: 0
Сумма: 12
```

### Задание 4. Поиск буквы

Пользователь вводит слово и одну букву. Напишите программу, которая
подсчитывает, сколько раз эта буква встречается в слове. Считайте, что
слово и буква вводятся в нижнем регистре.

**Пример:**

``` text
Введите слово: программа
Введите букву: р
Количество: 2
```

## Часть 2. Работа со списками и объединение конструкций (80 минут)

### Задание 5. Сумма чётных элементов

Дан список:

``` python
numbers = [3, 8, 5, 12, 7, 4, 9]
```

Напишите программу, которая находит сумму **только чётных** элементов
списка.

**Ожидаемый результат:**

``` text
Сумма чётных чисел: 24
```

**Ограничение:** не используйте `sum()`.

### Задание 6. Поиск имени

Дан список:

``` python
names = ["Анна", "Иван", "Мария", "Али", "Олег"]
```

Пользователь вводит имя. Программа должна проверить, есть ли такое имя в
списке, и вывести `Имя найдено` или `Имя не найдено`.

**Пример:**

``` text
Введите имя: Мария
Имя найдено
```

**Ограничение:** не используйте оператор `in` для проверки наличия имени
в списке. Выполните поиск с помощью цикла.

### Задание 7. Замена отрицательных чисел

Дан список:

``` python
numbers = [5, -3, 8, -1, 4, -6, 2]
```

Напишите программу, которая заменяет **все отрицательные элементы**
списка на `0`. После замены выведите получившийся список.

**Ожидаемый результат:**

``` text
[5, 0, 8, 0, 4, 0, 2]
```

### Задание 8. Анализ оценок

Дан список оценок студента:

``` python
grades = [5, 4, 3, 5, 2, 4, 5]
```

Напишите программу, которая:

1.  Вычисляет сумму всех оценок.
2.  Подсчитывает количество пятёрок.
3.  Находит среднюю оценку.

**Ожидаемый результат:**

``` text
Сумма оценок: 28
Количество пятёрок: 3
Средняя оценка: 4.0
```

**Ограничение:** не используйте `sum()`.

### Задание 9. Числа без пятёрки

Выведите числа от **1 до 20**, пропуская все числа, которые делятся на
5. Используйте `continue`.

**Ожидаемый результат:**

``` text
1 2 3 4 6 7 8 9 11 12 13 14 16 17 18 19
```

### Задание 10. Первое отрицательное число

Дан список:

``` python
numbers = [7, 4, 9, -3, 5, -8]
```

Найдите **первое отрицательное число** и выведите его. После нахождения
прекратите перебор с помощью `break`.

**Ожидаемый результат:**

``` text
Первое отрицательное число: -3
```
