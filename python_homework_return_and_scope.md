# Домашнее задание по Python

## Темы: возвращаемые значения функций, локальные и глобальные переменные

**Цель:** закрепить использование оператора `return`, параметров функций, локальных и глобальных переменных, глобальных констант и передачу результатов между функциями.

## Требования к выполнению

- Каждое задание выполните отдельно.
- Используйте указанные названия функций и переменных.
- В вычислительных функциях возвращайте результат через `return`, а выводите его через `print()` за пределами функции.
- Для промежуточных вычислений используйте локальные переменные.
- Используйте `global` только в заданияии, где это прямо указано.
- Проверьте программы на приведённых примерах.
- В заданиях на предсказание результата сначала запишите ответ, затем запустите код и проверьте себя.

## Часть 4. Итоговый мини-проект «Магазин игровых предметов»

### Задание 15. Покупка предметов в игре

Разработайте небольшую программу, которая рассчитывает стоимость игровых предметов, проверяет баланс игрока и выполняет покупку.

В игровом магазине действуют следующие условия:

- Один предмет стоит 100 монет.
- При покупке пяти и более предметов предоставляется скидка 10%.
- Покупка доступна только при достаточном количестве монет.

#### Этап 1. Глобальные константы

Создайте две глобальные константы:

```python
ITEM_PRICE = 100
DISCOUNT_PERCENT = 10
```

#### Этап 2. Стоимость покупки

Создайте функцию `calculate_total(quantity)`, которая принимает количество предметов и возвращает их общую стоимость без скидки.

**Проверка:** `calculate_total(5)` должна возвращать `500`.

#### Этап 3. Расчёт скидки

Создайте функцию `get_discount(quantity, total)`, которая возвращает размер скидки в монетах:

- Если количество предметов меньше пяти, вернуть `0`.
- Если количество предметов равно пяти или больше, рассчитать скидку с использованием константы `DISCOUNT_PERCENT`.

**Проверка:**

```python
print(get_discount(2, 200))
print(get_discount(5, 500))
```

**Ожидаемый результат:**

```text
0
50.0
```

#### Этап 4. Итоговая стоимость

Создайте функцию `calculate_purchase(quantity)`, которая использует функции `calculate_total()` и `get_discount()`.

Функция должна возвращать два значения: размер скидки и итоговую стоимость покупки.

**Проверка:** `calculate_purchase(5)` должна возвращать `(50.0, 450.0)`.

#### Этап 5. Проверка баланса

Создайте функцию `can_buy(balance, total)`, которая возвращает `True`, если монет достаточно для покупки, и `False` в противном случае.

#### Этап 6. Выполнение покупки

Создайте функцию `buy_items(balance, total)`, которая использует `can_buy()`.

- Если покупка доступна, вернуть баланс за вычетом стоимости покупки.
- Если монет недостаточно, вернуть прежний баланс.

Не используйте `global`: передавайте баланс через параметр и сохраняйте новое значение после вызова функции.

#### Этап 7. Основная программа

Используйте следующие исходные данные:

```python
balance = 1000
quantity = 5
```

Вызовите созданные функции, сохраните результаты и выведите информацию о покупке.

**Ожидаемый результат:**

```text
========== ИГРОВОЙ МАГАЗИН ==========

Начальный баланс: 1000
Количество предметов: 5
Стоимость без скидки: 500
Скидка: 50.0
Итоговая стоимость: 450.0

Покупка выполнена!
Остаток монет: 550.0
```

Проверьте программу также для других исходных данных:

| Начальный баланс | Количество предметов | Итоговая стоимость | Остаток монет | Покупка |
|---:|---:|---:|---:|---|
| 1000 | 2 | 200 | 800 | Доступна |
| 450 | 5 | 450.0 | 0.0 | Доступна |
| 300 | 5 | 450.0 | 300 | Недоступна |

Если покупка недоступна, программа должна вывести сообщение «Недостаточно монет!» и сохранить прежний баланс.

В основной версии проекта можно считать, что количество предметов — положительное целое число, а баланс — неотрицательное число.

**Дополнительное задание (по желанию):** добавьте ввод количества предметов и баланса с клавиатуры.
