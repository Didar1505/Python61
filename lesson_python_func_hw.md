# Домашнее задание по Python

**Тема:** Функции, параметры, аргументы и возвращаемое значение `return`.

**Цель:** Научиться создавать функции, передавать им аргументы и использовать возвращаемые значения.

## Часть 1. Функции без параметров

### Задание 1. Приветствие

Создайте функцию `greeting()`, которая выводит на экран сообщение:

```text
Привет! Я изучаю функции в Python!
```

Вызовите функцию три раза.

### Задание 2. Информация о студенте

Создайте функцию `student_info()`, которая выводит три строки:

```text
Имя: Алексей
Возраст: 16
Предмет: Программирование
```

Вызовите функцию два раза.

## Часть 2. Функции с параметрами

### Задание 3. Персональное приветствие

Создайте функцию `hello(name)`, принимающую имя человека и выводящую приветствие.

Пример вызова:

```python
hello("Анна")
hello("Иван")
```

Ожидаемый результат:

```text
Привет, Анна!
Привет, Иван!
```

### Задание 4. Таблица умножения

Создайте функцию `multiply(a, b)`, которая принимает два числа и выводит результат их умножения.

Пример:

```python
multiply(5, 3)
multiply(7, 4)
```

Ожидаемый результат:

```text
15
28
```

### Задание 5. Возраст человека

Создайте функцию `age_info(name, age)`, принимающую имя и возраст человека.

Функция должна выводить сообщение:

```text
Алексей, тебе 18 лет.
```

Вызовите функцию для трёх разных людей.

## Часть 3. Возвращаемое значение `return`

### Задание 6. Сумма двух чисел

Создайте функцию `add(a, b)`, которая принимает два числа и **возвращает** их сумму с помощью `return`.

Вызовите функцию, сохраните результат в переменную `result` и выведите её значение.

### Задание 7. Квадрат числа

Создайте функцию `square(number)`, возвращающую квадрат переданного числа.

Пример:

```python
print(square(4))
print(square(7))
```

Ожидаемый результат:

```text
16
49
```

### Задание 8. Определение большего числа

Создайте функцию `maximum(a, b)`, которая принимает два числа и возвращает большее из них.

Используйте условие `if/else`.

Пример:

```python
print(maximum(10, 25))
print(maximum(30, 12))
```

Ожидаемый результат:

```text
25
30
```

### Задание 9. Перевод минут в секунды

Создайте функцию `minutes_to_seconds(minutes)`, которая принимает количество минут и возвращает количество секунд.

Пример:

```python
print(minutes_to_seconds(5))
print(minutes_to_seconds(10))
```

Ожидаемый результат:

```text
300
600
```

## Часть 4. Небольшая практическая задача

### Задание 10. Калькулятор покупок

Создайте две функции:

- `calculate_price(price, quantity)` — принимает цену одного товара и количество, возвращает общую стоимость.
- `show_total(total)` — принимает общую стоимость и выводит сообщение о покупке.

Пример работы программы:

```text
Цена товара: 150
Количество: 3
Итого к оплате: 450 рублей
```

Используйте `input()` для ввода цены и количества товаров. Полученную стоимость передайте второй функции.

---

## Требования к выполнению

- Каждое задание выполнить с использованием `def`.
- Соблюдать отступы в теле функции.
- В заданиях 6–10 использовать `return` там, где требуется возвращаемое значение.
- Проверить работу каждой функции на нескольких примерах.
- Не использовать готовые функции `max()`, `sum()` и другие там, где нужно самостоятельно реализовать вычисление.
