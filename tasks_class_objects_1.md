# Практическая работа по Python

## Тема: Классы и объекты

**Цель:** научиться создавать классы и объекты, определять атрибуты и методы, использовать конструктор и деструктор.

**Материал для изучения:** https://metanit.com/python/tutorial/7.1.php

### Задание 1. Создание первого класса

Создайте класс `Animal`, который пока не содержит атрибутов и методов.

1. Используйте ключевое слово `class`.
2. Внутри класса используйте оператор `pass`.
3. Создайте три объекта класса: `animal1`, `animal2`, `animal3`.
4. Выведите каждый объект на экран.

### Задание 2. Создание объектов

Создайте класс `City`.

1. Создайте три объекта этого класса.
2. Каждому объекту добавьте атрибут `name` с названием города.
3. Добавьте атрибут `population` с численностью населения.
4. Выведите названия и население всех трёх городов.
5. Измените население одного города и повторно выведите его характеристики.

### Задание 3. Использование конструктора

Создайте класс `Robot`.

1. Определите метод `__init__(self)`.
2. Внутри метода выведите сообщение «Робот создан».
3. Создайте три объекта класса `Robot`.
4. Убедитесь, что при создании каждого объекта появляется сообщение.

### Задание 4. Конструктор с параметрами

Создайте класс `Book`.

Конструктор должен принимать следующие параметры:

- `title` — название книги.
- `author` — автор.
- `year` — год издания.

Создайте четыре объекта класса `Book` с разными значениями.

Выведите сведения обо всех книгах, обращаясь к атрибутам каждого объекта.

### Задание 5. Работа с атрибутами объектов

Создайте класс `Laptop`.

Атрибуты:

- `brand` — производитель.
- `ram` — объём оперативной памяти.
- `price` — стоимость.

Создайте два ноутбука.

1. Выведите характеристики обоих ноутбуков.
2. Увеличьте объём оперативной памяти первого ноутбука на 8 ГБ.
3. Уменьшите стоимость второго ноутбука на 10%.
4. Выведите обновлённые характеристики.

### Задание 6. Добавление атрибутов после создания объекта

Создайте класс `Employee` с атрибутами `name` и `salary`, которые устанавливаются через конструктор.

1. Создайте объект сотрудника.
2. После создания объекта добавьте ему новый атрибут `department` — название отдела.
3. Выведите все три атрибута.
4. Создайте второго сотрудника.
5. Попробуйте обратиться к атрибуту `department` второго сотрудника, не добавляя его заранее.
6. Объясните, почему возникает ошибка.

### Задание 7. Создание методов

Создайте класс `Dog`.

Конструктор должен принимать имя собаки.

Реализуйте методы:

- `bark()` — выводит сообщение «Гав-гав!».
- `sleep()` — выводит сообщение «Собака спит».
- `show_name()` — выводит имя собаки.

Создайте два объекта класса `Dog` с разными именами.

Вызовите все методы для каждого объекта.

### Задание 8. Методы с параметрами

Создайте класс `Calculator`.

Реализуйте четыре метода:

- `add(a, b)` — выводит сумму двух чисел.
- `subtract(a, b)` — выводит разность.
- `multiply(a, b)` — выводит произведение.
- `divide(a, b)` — выводит частное.

Создайте объект калькулятора.

Вызовите все методы с различными числами.

Для метода `divide()` предусмотрите проверку деления на ноль.

### Задание 9. Изменение атрибутов через методы

Создайте класс `Car`.

Конструктор принимает:

- `brand` — марка автомобиля.
- `speed` — текущая скорость.

Реализуйте методы:

- `accelerate(value)` — увеличивает скорость автомобиля на заданное положительное число.
- `brake(value)` — уменьшает скорость на заданное положительное число.
- `show_info()` — выводит марку автомобиля и его скорость.

Скорость автомобиля не должна становиться отрицательной.

Создайте объект автомобиля с начальной скоростью 0 км/ч.

Последовательно выполните следующие операции:

1. Увеличьте скорость на 40 км/ч.
2. Увеличьте скорость ещё на 30 км/ч.
3. Уменьшите скорость на 20 км/ч.
4. Выведите конечную скорость.

**Ожидаемый результат:** 50 км/ч.

### Задание 10. Взаимодействие методов внутри класса

Создайте класс `Player`.

Конструктор должен принимать:

- `nickname` — игровой никнейм.
- `health` — количество здоровья.

Реализуйте методы:

- `show_info()` — выводит никнейм и здоровье.
- `take_damage(damage)` — уменьшает здоровье на указанное положительное число.
- `heal(amount)` — восстанавливает здоровье на указанное положительное число.
- `check_status()` — проверяет состояние игрока.

Метод `check_status()` должен выводить:

- «Игрок жив», если здоровье больше нуля.
- «Игрок погиб», если здоровье равно нулю.

Здоровье не должно опускаться ниже нуля.

После получения урона метод `take_damage()` должен автоматически вызывать `check_status()` через `self`.

Создайте игрока со 100 единицами здоровья и проверьте работу всех методов.

### Задание 11. Использование деструктора

Создайте класс `Document`.

1. Конструктор принимает название документа.
2. При создании объекта выводится сообщение «Документ [название] создан».
3. Добавьте метод `__del__(self)`.
4. Внутри деструктора выводите сообщение «Документ [название] удалён».
5. Создайте объект документа.
6. Удалите ссылку на объект с помощью `del`.
7. Проверьте результат выполнения программы.

**Примечание:** точное время вызова `__del__()` зависит от реализации Python и наличия других ссылок на объект. Удаление переменной через `del` не всегда означает немедленное уничтожение объекта.

### Задание 12. Итоговая задача «Управление банковским счётом»

Создайте класс `BankAccount`.

Конструктор принимает:

- `owner` — имя владельца.
- `balance` — начальный баланс.

Реализуйте следующие методы:

- `show_info()` — показывает владельца и текущий баланс.
- `deposit(amount)` — пополняет счёт.
- `withdraw(amount)` — снимает деньги со счёта.
- `send_money(other_account, amount)` — переводит деньги другому объекту класса `BankAccount`.

**Условия работы:**

1. Нельзя пополнять счёт на отрицательную сумму или ноль.
2. Нельзя снять больше денег, чем имеется на счёте.
3. Сумма перевода должна быть положительной.
4. При переводе деньги должны списываться с одного счёта и поступать на другой.
5. После каждой операции можно проверить баланс через `show_info()`.

Создайте два объекта:

- Счёт Ивана: 5000 рублей.
- Счёт Анны: 2000 рублей.

Выполните операции:

1. Пополните счёт Ивана на 1500 рублей.
2. Снимите со счёта Анны 500 рублей.
3. Переведите 2000 рублей со счёта Ивана на счёт Анны.
4. Выведите итоговые балансы обоих счетов.

**Ожидаемый результат:**

```text
Иван: 4500 рублей
Анна: 3500 рублей
```
