## Часть 1. Что такое `elif`?

`elif` — сокращение от *else if*, то есть «иначе, если».

Он используется, когда нужно проверить несколько вариантов по очереди. Python проверяет условия сверху вниз:
1. Если условие `if` истинно, выполняется его блок, а остальные ветви этой цепочки пропускаются.
2. Если `if` ложно, Python проверяет первый `elif`.
3. Если он тоже ложен, проверяется следующий `elif`, если он есть.
4. Если ни одно условие не подошло, выполняется `else`, если он указан.

В одной цепочке может быть несколько ветвей `elif`, но только один `if` в начале. `else` необязателен и, если используется, должен стоять в конце.

```python
temperature = 22

if temperature < 0:
    print("Мороз")
elif temperature < 15:
    print("Холодно")
elif temperature < 25:
    print("Тепло")
else:
    print("Жарко")
```

В этом примере при температуре `22` выводится `Тепло`.

Обратите внимание: в `elif temperature < 25` не нужно повторять `temperature >= 15`. Python дошёл до этой ветви только потому, что предыдущие условия уже оказались ложными.

## Часть 2. Простые примеры

### Пример 1. Положительное число, отрицательное число или ноль

```python
number = -4

if number > 0:
    print("Положительное число")
elif number < 0:
    print("Отрицательное число")
else:
    print("Ноль")
```

### Пример 2. Оценка по баллам

Предположим, что баллы распределяются так:
- 90–100 — отлично;
- 70–89 — хорошо;
- 50–69 — удовлетворительно;
- меньше 50 — неудовлетворительно.

```python
score = 76

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
elif score >= 50:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

**Почему условия идут именно в таком порядке?**

Если начать с `score >= 50`, то балл `95` тоже удовлетворит этому условию, и программа может вывести неправильную оценку. Поэтому в этой цепочке сначала проверяется самый высокий порог, затем более низкие.

### Пример 3. Выбор действия по команде

```python
command = "pause"

if command == "start":
    print("Запуск")
elif command == "pause":
    print("Пауза")
elif command == "stop":
    print("Остановка")
else:
    print("Неизвестная команда")
```

### Пример 4. `elif` вместе с логическими операторами

В ветвях `if` и `elif` можно использовать `and`, `or` и `not`.

```python
age = 20
has_ticket = True

if age < 0:
    print("Возраст указан неверно")
elif age >= 18 and has_ticket:
    print("Вход разрешён")
elif age >= 18 and not has_ticket:
    print("Нужен билет")
else:
    print("Вход разрешён только с 18 лет")
```

## Часть 3. Несколько `if` или цепочка `if` / `elif`?

Это важное различие.

### Вариант A. Несколько независимых `if`

Каждый `if` проверяется отдельно. Поэтому может выполниться несколько блоков.

```python
number = 12

if number > 0:
    print("Число положительное")

if number % 2 == 0:
    print("Число чётное")

if number > 10:
    print("Число больше 10")
```

Для числа `12` программа выведет все три сообщения, потому что все три условия истинны.

### Вариант B. Цепочка `if` / `elif` / `else`

Выполняется только первая подходящая ветвь. После неё Python пропускает остальные ветви этой цепочки.

```python
number = 12

if number > 0:
    print("Число положительное")
elif number % 2 == 0:
    print("Число чётное")
elif number > 10:
    print("Число больше 10")
```

Здесь появится только `Число положительное`. Даже если другие условия истинны, Python не проверяет следующие ветви после выполнения первого подходящего блока.

### Сравните два подхода

| Несколько `if` | `if` / `elif` / `else` |
|---|---|
| Каждое условие проверяется отдельно | Условия проверяются по очереди до первого истинного |
| Могут выполниться несколько блоков | В цепочке выполняется максимум один блок |
| Подходит для независимых проверок | Подходит для взаимоисключающих вариантов |

**Как выбрать?**
- Используйте несколько `if`, если программа должна проверить все условия независимо.
- Используйте `elif`, если нужно выбрать один вариант из нескольких.

### Пример: определение свойств числа

Нужно сообщить и о положительности числа, и о его чётности. Это две независимые характеристики, поэтому уместны два `if`.

```python
number = 8

if number > 0:
    print("Положительное")

if number % 2 == 0:
    print("Чётное")
```

А теперь нужно выбрать только одну категорию размера числа: маленькое, среднее или большое. Здесь подходит `if` / `elif` / `else`.

```python
number = 8

if number < 0:
    print("Отрицательное")
elif number <= 10:
    print("Небольшое число")
else:
    print("Большое число")
```

## Итог занятия

- `if` проверяет первое условие.
- `elif` проверяет следующий вариант, только если предыдущие условия в этой цепочке ложны.
- `else` выполняется, если ни одно предыдущее условие цепочки не подошло.
- Несколько независимых `if` могут выполнить несколько блоков.
- В одной цепочке `if` / `elif` / `else` выполняется максимум один блок.
