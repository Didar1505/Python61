# Практическая работа: Code Review — найди и исправь ошибки

**Тема:** Синтаксис Python и цикл `for`.

**Цель:** Научиться находить и исправлять синтаксические ошибки в программах на Python.

## Инструкция

В каждой программе есть одна или несколько **синтаксических ошибок**. Прочитайте описание, изучите код, найдите ошибки и исправьте их так, чтобы программа выполняла поставленную задачу.

Для каждого задания:

1. Определите, в какой строке находится ошибка.
2. Объясните, какое правило синтаксиса Python нарушено.
3. Исправьте код.
4. Запустите программу и проверьте результат.

**Ограничения:** Используйте только знакомые конструкции: переменные, арифметические операции, `print()`, `input()`, `int()`, `float()`, `if/else`, `for` и `range()`. Не используйте вложенные циклы, списки и `while`.

## Задание 10. Чётное или нечётное

Программа проверяет числа от 1 до 5 и сообщает, является каждое число чётным или нечётным.


## Задание 13. Итоговый Code Review

**В этом задании допущено несколько синтаксических ошибок.**

Программа должна запросить количество товаров, затем цену каждого товара. Если цена больше 1000 рублей, применяется скидка 10%. В конце выводится общая стоимость покупки.

```python
count = int(input("Количество товаров: "))
total = 0

for i range(count)
    price = float(input("Цена товара: "))

    if price > 1000
        price = price * 0.9
    else:
        price = price

    total = total + price

print("Итоговая стоимость:", total
```
