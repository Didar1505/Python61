# Code Review — Синтаксис цикла `while`

**Задание:** проверьте каждый фрагмент кода. Если есть ошибки — исправьте. Если код правильный — оставьте без изменений.

## Задание 1

```python
i = 1
while i <= 5
    print(i)
    i += 1
```

Некоторые фрагменты **полностью правильные**, некоторые содержат **синтаксические ошибки**, а отдельные могут выполняться, но иметь **логические проблемы**. Задача — научиться различать эти случаи.
