# Диагностическая практическая работа по Python

**Цель:** проверить базовые знания Python и умение самостоятельно решать
простые задачи.

**Время:** 40--50 минут.

**Условие:** решайте задания самостоятельно, используя только изученные
конструкции Python. Не используйте пользовательские функции и вложенные
циклы.

## Задание 1. Проверка возраста

Напишите программу, которая запрашивает возраст пользователя.

-   Если возраст 18 лет или больше, выведите `Совершеннолетний`.
-   Иначе выведите `Несовершеннолетний`.

**Пример:**

``` text
Введите возраст: 16
Несовершеннолетний
```

## Задание 2. Проверка числа

Напишите программу, которая запрашивает целое число и определяет,
является ли оно положительным, отрицательным или равным нулю.

**Пример:**

``` text
Введите число: -7
Отрицательное
```

## Задание 3. Чётные числа

Напишите программу, которая запрашивает число `N` и выводит все чётные
числа от 1 до `N` включительно.

**Пример:**

``` text
Введите N: 10
2 4 6 8 10
```

## Задание 4. Сумма чисел

Напишите программу, которая запрашивает число `N` и вычисляет сумму всех
целых чисел от 1 до `N` включительно.

**Пример:**

``` text
Введите N: 5
Сумма: 15
```

## Задание 5. Проверка пароля

Напишите программу, которая запрашивает пароль до тех пор, пока
пользователь не введёт `python123`.

После правильного ввода выведите `Доступ разрешён`.

**Пример:**

``` text
Введите пароль: 1234
Неверный пароль
Введите пароль: python123
Доступ разрешён
```

## Задание 6. Работа со строкой

Напишите программу, которая запрашивает слово и подсчитывает количество
букв `а` в нём.

Считайте, что слово вводится маленькими буквами.

**Пример:**

``` text
Введите слово: банан
Количество букв а: 2
```

## Задание 7. Числа больше 10

Дан список:

``` python
numbers = [5, 12, 7, 20, 3, 16, 9]
```

Напишите программу, которая выводит только числа больше 10.

**Ожидаемый результат:**

``` text
12
20
16
```

## Задание 8. Анализ списка

Дан список:

``` python
numbers = [4, 7, 2, 9, 6, 3, 8]
```

Напишите программу, которая:

1.  Вычисляет сумму всех чисел.
2.  Подсчитывает количество чётных чисел.
3.  Находит самое большое число.

**Ожидаемый результат:**

``` text
Сумма: 39
Количество чётных: 4
Максимальное число: 9
```

**Ограничение:** не используйте готовые функции `sum()` и `max()`.
