# Практика Python: осмысленные задачи на `if` и `if / else`

## Цель

В этих заданиях мы используем условия не просто для сравнения чисел, а для принятия решений в реальных ситуациях.

Мы пока используем только:

- `input()`
- `int()`
- `print()`
- операторы сравнения
- `if`
- `else`

Без `elif`, `and`, `or`.

# 1. Проверка скорости автомобиля

Пользователь вводит скорость автомобиля.

Ограничение скорости — **60 км/ч**.

Если скорость выше 60, программа должна вывести:

```text
Превышение скорости!
```

Иначе:

```text
Скорость в норме.
```

```python
speed = int(input("Введите скорость автомобиля: "))

if speed > 60:
    print("Превышение скорости!")
else:
    print("Скорость в норме.")
```

## Попробуйте

Запустите программу несколько раз:

```text
40
60
61
100
```

Обратите внимание на значение `60`.

При скорости ровно `60` условие `speed > 60` является ложным.

# 2. Достаточно ли денег на покупку

Пользователь вводит:

- свой баланс;
- цену товара.

Если денег хватает, программа выводит:

```text
Покупка возможна
```

Иначе:

```text
Недостаточно средств
```

```python
balance = int(input("Ваш баланс: "))
price = int(input("Цена товара: "))

if balance >= price:
    print("Покупка возможна")
else:
    print("Недостаточно средств")
```

## Вопрос

Почему здесь используется `>=`, а не просто `>`?

Потому что если баланс **точно равен** цене товара, покупку всё равно можно совершить.

# 4. Можно ли скачать файл

Пользователь вводит:

- размер файла;
- количество свободного места.

Если файл помещается на диск, вывести:

```text
Файл можно скачать
```

Иначе:

```text
Недостаточно места
```

```python
file_size = int(input("Размер файла в МБ: "))
free_space = int(input("Свободное место в МБ: "))

if file_size <= free_space:
    print("Файл можно скачать")
else:
    print("Недостаточно места")
```

## Пример

```text
Размер файла: 500
Свободное место: 1000
```

Результат:

```text
Файл можно скачать
```

Но если:

```text
Размер файла: 1500
Свободное место: 1000
```

получим:

```text
Недостаточно места
```

# 6. Доступ к игре по возрасту

У игры возрастное ограничение **16+**.

Пользователь вводит свой возраст.

Если возраст подходит, игра запускается.

Иначе доступ запрещён.

```python
age = int(input("Введите возраст: "))

if age >= 16:
    print("Можно запустить игру")
else:
    print("Доступ запрещён")
```

## Главная идея

Выражение:

```python
age >= 16
```

сначала превращается в:

```text
True
```

или:

```text
False
```

После этого `if` решает, какой код выполнять.

# 8. Система выдачи товара со склада

Пользователь вводит:

- сколько товара находится на складе;
- сколько товара хочет заказать клиент.

Если товара достаточно:

- заказ выполняется;
- программа показывает, сколько товара останется.

Если товара недостаточно:

```text
Недостаточно товара на складе
```

```python
stock = int(input("Товаров на складе: "))
order = int(input("Количество в заказе: "))

if order <= stock:
    print("Заказ можно выполнить")
    print("После заказа останется:", stock - order)
else:
    print("Недостаточно товара на складе")
```

## Почему это хороший пример?

Внутри одного `if` можно выполнять несколько инструкций:

```python
print(...)
print(...)
```

Главное — чтобы они имели одинаковый отступ.

# Итоги

После выполнения этих задач студент должен понимать:

- условие — это выражение, которое даёт `True` или `False`;
- `if` выполняет код только при истинном условии;
- `else` выполняется, когда условие ложно;
- выбор правильного оператора сравнения важен;
- условия позволяют программе принимать решения в зависимости от данных пользователя.
